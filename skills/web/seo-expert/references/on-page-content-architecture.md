# On-Page Content Architecture & Intent Mapping

On-page SEO aligns semantic HTML structure with user search intent, demonstrating clear E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness) to search algorithms.

## 1. Title Tag & Meta Description Formulas

### Title Tag Standard
- Length: 50-60 characters (exceeding ~580px truncates with ellipsis in SERPs).
- Formula: `Primary Keyword - Secondary Benefit | Brand Name`
- Bad: `Home - PT Acme Indonesia Official Website`
- Good: `Semen Gresik 50kg Distributor Resmi | Pengiriman Cepat - PT Acme`

### Meta Description Standard
- Length: 120-155 characters.
- Formula: `[Problem / Agitation] + [Concrete Solution] + [Call to Action / Differentiator]`.
- Bad: `Kami adalah penyedia semen terpercaya sejak tahun 1990 melayani seluruh Indonesia.`
- Good: `Cari semen berkualitas untuk proyek gedung? Dapatkan semen sak dan curah harga pabrik dengan armada pengiriman 24 jam. Minta penawaran hari ini!`

## 2. Heading Hierarchy & Semantic Scaffolding

Strict semantic rules:
1. **Single `<h1>` Per Page:**
   - Must encapsulate the primary keyword and topic thesis.
   - Example: `<h1>Panduan Lengkap Modifikasi Sepeda Minion 2026</h1>`
2. **Logical `<h2>` Topic Sections:**
   - Sub-topics addressing high-volume related queries.
   - Include question-based headings (e.g., `<h2>Berapa Estimasi Biaya Modifikasi Sepeda Minion?</h2>`).
3. **Granular `<h3>` & `<h4>` Sub-units:**
   - Specific component breakdowns, specs, and step-by-step instructions.
   - Never skip levels (e.g., jump directly from `<h2>` to `<h4>`).

## 3. Search Intent Mapping Matrix

| Search Intent | User Goal | Query Examples | Content Layout Required |
|---|---|---|---|
| **Informational** | Learn a topic, troubleshoot | *"cara menyetel rd shimano acera"*, *"apa itu chainline sepeda"* | Comprehensive guides, diagrams, step-by-step walkthroughs, FAQs. |
| **Navigational** | Find a specific brand/tool | *"shopee indonesia"*, *"hermes gateway login"* | Clear brand landing page, fast login/entry links. |
| **Commercial Investigation** | Compare options before buying | *"rekomendasi rd 7 speed terbaik"*, *"shimano acera vs tourney"* | Comparison tables, pros/cons, benchmark testing, buyer verdicts. |
| **Transactional** | Ready to purchase or sign up | *"beli rd acera rd-m3020 surabaya"*, *"harga semen gresik 50kg"* | Product pages, clear pricing, inventory status, fast checkout CTA. |

## 4. Internal Linking & SILO Architecture

Search engines understand site authority through topical clusters:
1. **Pillar Page (Top of SILO):** Broad thematic anchor (e.g., `/sepeda-komuter/`).
2. **Cluster Pages (Sub-topics):** Deep dives linking back to the pillar (e.g., `/sepeda-komuter/drivetrain-7-speed/`).
3. **Anchor Text Discipline:**
   - Use descriptive, keyword-rich anchor text (`"baca panduan transmisi 7-speed"`).
   - Avoid generic anchor text (`"klik disini"`, `"link ini"`, `"baca selengkapnya"`).
   - Maintain breadcrumb trails on all sub-pages (`Home > Kategori > Produk`).
