# Expert Review Checklist

Use this for a professional UI typography and content design review.

## A. Information hierarchy
- Can a first-time user identify the screen purpose in a quick scan?
- Is there one obvious primary action when the flow requires one?
- Do heading levels reflect real information structure?
- Are supporting descriptions visually subordinate?
- Are repeated UI roles styled consistently?

## B. Typography system
- Are there unnecessary font sizes or weights?
- Is the body size appropriate for platform and context?
- Is line-height comfortable for multi-line text?
- Are long paragraphs constrained to a readable measure?
- Is display type scaled down appropriately on small screens?
- Are small labels legible and not overly thin?
- Do numerals align appropriately in data-heavy views?
- Does the chosen font support required languages and symbols?

## C. Copy quality
- Does each heading communicate a useful idea?
- Do buttons name actions or outcomes?
- Can labels make sense without nearby explanatory paragraphs?
- Is helper text preventing a real uncertainty?
- Are redundant words removed?
- Is terminology consistent across the flow?
- Does the copy sound natural in the target language?

## D. Forms and errors
- Are labels persistent?
- Are format requirements shown before failure when helpful?
- Are errors specific to the actual problem?
- Does every error provide a recovery path?
- Is user-entered data preserved after validation failure?
- Are errors associated with the correct field in implementation?

## E. States
- Does each empty state match the reason for emptiness?
- Are loading messages truthful about what is happening?
- Do success messages confirm the actual outcome?
- Are destructive dialogs precise about scope and reversibility?
- Are permission prompts transparent about purpose?

## F. Product/offer copy
- Is the value proposition understandable without buzzwords?
- Are features connected to user outcomes?
- Is the CTA consistent with the level of commitment?
- Are pricing, renewal, limits, and conditions clear?
- Are all metrics, testimonials, and proof verifiable?
- Is urgency real rather than manufactured?

## G. Accessibility and resilience
- Does text resize without clipping or overlap?
- Can text spacing be increased without loss of content/functionality?
- Are controls robust to longer translations?
- Is essential content available without hover-only disclosure?
- Is meaningful text selectable/copyable when useful?
- Are all-caps and low-contrast text used sparingly?

## H. Final polish
- Read every string aloud.
- Remove words that do not change meaning.
- Check grammar parallelism in lists and options.
- Check punctuation and capitalization rules.
- Check singular/plural behavior.
- Check zero, one, many, and maximum-length data states.
- Check mobile, desktop, and accessibility text sizes.
