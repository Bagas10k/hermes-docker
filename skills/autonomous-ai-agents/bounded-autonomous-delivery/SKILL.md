# Bounded autonomous delivery
Set objective, verifiable done condition, turn/time cap, and forbidden side effects. Use built-in Hermes `/goal` for repeated turns; do not build another loop daemon. Execute reversible reads, coding, and tests without asking; pause for genuinely missing authorization, secrets, purchase, deploy, publication, push, or destructive change. Prefer the cheapest discriminating test per turn; do not burn tokens for their own sake. Stop with verified success, explicit blocker, or budget. `approvals.mode=off` is not blanket consent.
