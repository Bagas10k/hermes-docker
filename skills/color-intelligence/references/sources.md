# Authoritative Sources

Use these sources when a task needs standards-level verification or up-to-date implementation details.

- W3C WAI — WCAG 2.2 Understanding SC 1.4.3 Contrast (Minimum): https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
- W3C WAI — WCAG 2.2 Understanding SC 1.4.1 Use of Color: https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html
- W3C WAI — Technique G18, contrast calculation and 4.5:1 technique: https://www.w3.org/WAI/WCAG22/Techniques/general/G18.html
- MDN — CSS `oklch()` reference and browser compatibility: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/oklch

Treat implementation support as time-sensitive. Re-check current browser/tool support when compatibility is important.
