# Pedoman Ringkas UI/UX & Konten Anti-Slop (Otak Koding)

1. Subtraction Test: Jika dihapus tidak mengurangi fungsi, data, atau aksi pengguna, hapus elemen tersebut.
2. Anti-AI-Topper: Dilarang menaruh badge kapsul versi/marketing mengambang di atas headline.
3. Tipografi Poin-Poin: Judul tegas, deskripsi poin singkat faktual. Dilarang narasi pengantar panjang.
4. Compact Density: Radius kartu maks 12px, tombol 6-8px, padding vertikal proporsional.
5. Semantik Keuangan: Hijau = valid/balance, Merah = error/selisih, Kuning = review.
6. Angka: Wajib tabular-nums, format Rp dengan titik, kolom angka rata kanan.
7. Dimensi Tema Terang: Kanvas off-white (#FAF8F5/#FAF6EF) + kartu putih (#FFFFFF) + dual shadow (ambient + depth) + hairline border 1px + inner bevel highlight (inset 0 1px 0 rgba(255,255,255,0.9)). Dilarang tema putih datar tanpa elevasi.
8. Bingkai Foto Taktil (Archival Frame): Khusus kartu galeri referensi/pameran visual, gunakan sasis kertas warm ivory (#F5F2EB) dengan dagu bawah lebar khas polaroid untuk metadata monospace dan soft ambient shadow di atas kanvas gelap, menghindari kontainer borderless generik.
9. Source-Connected Design (Anti-Hallucination): Perancangan UI/UX dilarang hanya bersandar pada pengetahuan internal atau teks LLM semata. Wajib dihubungkan langsung ke program/MCP sumber komponen dan blok kode nyata (seperti Shadcn Studio MCP, UI-Layouts) serta bank visual terverifikasi (katalog referensi desain lokal) sebelum merangkai antarmuka.
10. Zero-Emoji Policy (Anti-Kitsch): Dilarang keras menyematkan karakter emoji Unicode di antarmuka UI/UX. Wajib 100% menggunakan ikon vektor garis SVG monokrom presisi (Lucide SVG) dengan stroke-width seragam.
11. Sasis Kartu Solid (Anti-Garis Tipis 3px): Dilarang menggunakan aksen garis tepi atas tipis (border-top 3px) pada kartu putih. Gunakan Sculpted Header Band bergradasi lembut dengan bayangan bertingkat (layered elevation) dan micro-card terstruktur.
12. Neo-Brutalism Fungsional (Pola Depo Budget): Border hitam tebal (2-2.5px solid #000), hard offset drop shadow (4px 4px 0 #000 tanpa blur), blok warna kontras tinggi (Cobalt #1669E8, Lime #C8E832, Sunflower #FBBF24, Coral #FF6B55, Teal #2DD4BF), kanvas warm cream (#FAF7F2) berkisi teknis (28px), pita ticker marquee berjalan mulus, dan interaksi hover translate(-2px, -2px) dengan bayangan memanjang 6-7px.
13. Mandor-Kuli Fan-Out untuk Halaman Penuh: Dilarang membuat prototipe setengah jalan atau stub. Kerahkan subagent spesialis secara paralel (Frontend, Backend, Obsidian) untuk menyelesaikan seluruh seksi dan fungsionalitas secara tuntas dan mandiri.
14. Sentinel Diagnostic HUD vs Banner Promosi: Pada dasbor sistem/telemetri, dilarang membuat banner promosi lebar yang santai/kasual. Rancang sebagai Modul HUD Diagnostik Taktil yang presisi (lencana maskot vektor 48-52px, status operasional hidup, dan chip metrik mono terstruktur seperti 100ms AKTIF, Buffer, Kernel Source).
15. Zero-Emoji Invariant Menyeluruh: Dilarang membiarkan karakter emoji Unicode menyelinap ke tag <title>, tombol tema (seperti kilauan), atau kategori mockup. Seluruh representasi visual wajib 100% menggunakan ikon vektor garis SVG monokrom presisi.
16. Dual-Engine MCP Workflow: Wajib menggunakan MCP lokal uiux-reference (uiux_search, uiux_view, uiux_reference_board, uiux_extract_patterns) untuk membedah 100 aset visual fisik di server sebelum mengambil sasis komponen kode produksi via @ui-layouts/mcp (search_components, get_source_code). Alur: Cari Pola -> Validasi Gambar Fisik -> Komparasi Board -> Ambil Sasis Komponen -> Implementasi Bersih Zero-Emoji.
17. Katalog 6 Arketipe Desain Kreatif (Anti-Desain Itu-Itu Terus): Hindari template generik atau bento card seragam. Panggil MCP uiux-reference (`uiux_creative_archetypes` dan `uiux_get_component_recipe`) untuk mengadopsi 6 arketipe desain berkarakter: (1) Isometric 3D Wireframe (kubus 3D kawat, monokrom minimalis), (2) Playful Storytelling Vector (kurva organik/blob, narasi ramah, palet pastel cerah), (3) Swiss Botanical ASCII (kisi arsitektural Swiss, seni teks botani ASCII, tipografi serba huruf kecil), (4) Neo-Brutalist Glitch (tekstur kertas, CMYK slice accents, transparansi alpha checkerboard), (5) Cyber HUD Cockpit (tachometer sirkular SVG, telemetri dark, synthesizer Web Audio), (6) Warm Paper & Obsidian (lembaran buku taktil, sudut lipatan kertas/paper peel, bayangan jilid).
18. The Candle-Lit System (Dark is a Lighting Choice): Gelap bukan sekadar pilihan warna latar belakang #000, melainkan pilihan tata pencahayaan (lighting choice). Tetapkan satu sumber cahaya terarah (misal: lilin di kiri atas) dan patuhi hukum fisikanya pada setiap elemen: tidak ada warna putih murni #ffffff (plafon warna terterang adalah pale green-grey #c8ceca), bayangan pekat selalu jatuh ke kanan-bawah, highlight halus hanya di sisi atas-kiri, tipografi digambar seperti label cetak mekanikal (printed label), dan intensitas halaman semakin meredup saat digulir ke bawah.
19. Creator Card Architecture (Tiga Variasi Perlakuan Potret A/B/C ala Dribbble/Figma): Mencegah kartu profil/produk yang monoton. Kuasai 3 teknik perlakuan visual: (1) Structured Inset (foto sebagai elemen inset mandiri beradius 20px, sasis putih bersih, margin 12px, memisahkan media dan teks secara tegas dengan kontras WCAG AA tertinggi), (2) Soft Vignette Fade (foto membentang ke tepi atas-kiri-kanan dan menyatu mulus ke sasis kartu via CSS mask gradient linear-gradient(to bottom, black 50%, rgba(0,0,0,0.85) 70%, transparent 98%) tanpa garis potong kaku), (3) Full-Bleed Frosted Glassmorphism (foto mengisi 100% container, separuh bawah menggunakan baki frosted glass backdrop-filter: blur(28px) saturate(190%) dengan highlight tepi atas 1px, tipografi terinversi putih bersih, lencana verifikasi frosted monokrom, dan tombol pill putih kontras tinggi dengan teks gelap). Lengkapi dengan fisika 3D perspective tilt (rotateX/Y maks 8-9 deg) dan kilatan specular glare effect reaktif kursor mouse.
20. Standar Redaksi Zero-Fluff & Visual Sinematik (Fabrizio Romano Benchmark): Pada akun warta atau publikasi media sosial, singkirkan kalimat pembuka klise generik (*"Laga sengit tersaji..."*, *"Sebuah pertandingan..."*). Baris pertama wajib menembak angka rekor, skor konkret, atau momen dramatis dengan huruf kapital (*"33 GOL DALAM 7 LAGA! ABSOLUTE CINEMA"*). Strukturkan naskah dalam poin-poin aksi fakta 1 baris padat per pemain kunci (angka dan peran jelas), lalu tutup dengan pertanyaan debat interaktif (CTA) untuk memicu komentar audiens. Wajib cantumkan atribusi sumber resmi di cover, slide akhir, dan caption. Visual: Gunakan filter kontras sinematik (1.18) dan saturasi terkalibrasi (1.12), utamakan foto selebrasi emosional ikonik beresolusi tinggi, dan kunci area $y = 140\text{ px}$ s/d $680\text{ px}$ sebagai zona steril subjek (headline di $y \ge 680\text{ px}$ agar tidak menabrak wajah atau ekspresi subjek).
21. Penyelarasan Mutlak Entitas Tokoh dengan Foto Visual (Anti-Salah Orang): Dilarang keras menampilkan pemain atau tokoh yang berbeda dengan subjek utama berita (misal: berita membahas Jay Idzes, tetapi foto menampilkan Erling Haaland). Prosedur kurasi: (1) Ekstraksi entitas nama tokoh kunci dari topik berita, (2) Verifikasi URL/token gambar feed RSS: dilarang memakai thumbnail bawaan feed jika URL-nya tidak memuat token nama tokoh guna menghindari logo klub atau pemain lawan terpilih acak, (3) Lakukan perburuan web spesifik menggunakan nama tokoh + kata kunci aksi selebrasi emosional, (4) Doktrin Fallback Netral: Jika pencarian foto tokoh di internet gagal, fallback HANYA diperbolehkan ke foto stadion/lapangan netral, HARAM mengambil foto pemain lain dari arsip lokal, (5) Cross-entity check di gerbang QC: Sub-agent QC wajib memindai kesesuaian tokoh berita vs URL/nama berkas gambar dan menjatuhkan VETO jika terdeteksi inkonsistensi nama pemain.
22. Autonomous Self-Healing & Root-Cause Re-Audit untuk Draf Ditolak QC: Jangan biarkan draf yang ditolak QC mati di database jika beritanya masih baru/segar. Lakukan Root Cause Analysis (RCA) secara mandiri: (1) Bedakan false-positive aturan redaksi (seperti regex mendeteksi kata slang emosional 'bantai' atau 'pesta gol' sebagai klaim hasil pertandingan tanpa skor pada artikel opini/warta reaksi) vs cacat substansial naskah, (2) Kalibrasi logika deteksi bila terjadi over-fitting false-positive, (3) Perbaiki naskah dan sinkronisasi entitas secara in-place lalu re-render, (4) Draf prediksi usang yang pertandingannya sudah selesai dialihkan ke status `ARCHIVED_STALE`, bukan dihapus sembarangan, (5) Jalankan audit ulang hingga memperoleh status `QC_APPROVED` 100/100.
23. Graf Pengetahuan Proprietary & Arsitektur 3D Interaktif (Otak Koding Neural Graph Benchmark):
    - Branding Proprietary: Dilarang mencantumkan nama/merek pihak ketiga (seperti 'Obsidian') di antarmuka publik atau dasbor internal. Wajib menggunakan penamaan mandiri milik sistem sendiri ('Otak Koding Neural Graph / Neural Swarm').
    - Eliminasi Disorientasi Spasial 3D: Kontrol orbit 3D murni membingungkan pengguna jika berdiri sendiri. Wajib selalu menyertakan Preset Sudut Pandang Cepat (Quick Camera Presets):
      - Tombol utama: 'Peta Atas (2.5D Orthogonal / Bird's Eye View)' untuk menetralkan disorientasi kamera 3D kembali ke tampilan peta konsep datar yang jelas.
      - Isometrik 3D, Tampak Depan, Tampak Samping, serta D-Pad navigasi terarah (pan, zoom, reset, auto-rotate).
    - Relasi Bersih (Garis Solid & Pendar Seleksi Kontras Tinggi): Dilarang menggunakan bola-bola partikel animasi yang berjalan di atas garis koneksi karena mengaburkan relasi dan memicu kelelahan visual. Gunakan garis koneksi solid bersih (1.2px) secara default. Saat sebuah node diklik/dipilih: nyalakan garis relasi terkait dengan pendar neon terang kontras tinggi (cyan neon #00f0ff, tebal 3.2px), sementara node dan garis di luar pohon koneksi langsung diredupkan (opacity 0.08).
    - Kompensasi Offset Bidang Pandang (Drawer Clearance): Saat laci samping (drawer catatan/inspektor) terbuka menutupi sebagian layar (misal 480px di kanan), lakukan penyesuaian posisi kamera ke arah berlawanan agar node yang dipilih tetap berada tepat di tengah area pandang terbuka.
24. WebGL Smart Inactivity Auto-Sleep (Konservasi Daya & 0% Background Resource):
    - Mesin 3D WebGL (Three.js / Force Graph) yang me-render loop animasi terus-menerus di latar belakang memakan daya baterai, GPU, dan alokasi memori peramban pengguna.
    - Wajib menerapkan mekanisme Smart Inactivity Auto-Sleep:
      - Pasang pendengar document.addEventListener('visibilitychange') untuk mendeteksi saat tab browser diminimalkan atau beralih tab, dipadukan dengan idle timer (45 detik s/d 5 menit tanpa interaksi pengguna).
      - Panggil Graph.pauseAnimation(), ubah lencana status HUD menjadi '3D HIBERNASI' / 'SLEEP', memangkas penggunaan GPU dan siklus render ke 0.0%.
      - Pasang event bangun tidur otomatis (pointermove, keydown, touchstart, tab aktif kembali) yang langsung memanggil Graph.resumeAnimation() tanpa perlu memuat ulang data graf.
      - Seluruh endpoint API data, pencarian catatan, dan pembaca Markdown tetap siaga dan dapat dioperasikan normal di latar belakang.
25. Pola Desain "Cute Candy Studio" / Tactile Pastel Pop (Penyelarasan Preferensi Gemas & Zero Emoji):
    - Saat pengguna meminta tema "cute", "gemas", "playful", atau "colorful", PANTANGAN MUTLAK EMOJI TETAP BERLAKU 100%. Dilarang menyematkan karakter emoji grafis Unicode.
    - Wujudkan impresi manis, cerah, dan playful murni melalui struktur visual taktil:
      a) Kanvas Marshmallow / Warm Porcelain: Alas dasar warm off-white (`#FAF7F2` atau `#FCFBF7`) dipadukan tekstur kisi dot-matrix halus (`radial-gradient(#E5DFD5 1px, transparent 1px)` jarak 20px).
      b) Palet Gummy Candy Pastel Terkalibrasi: Kombinasi Strawberry Milk Pink (`#F472B6`), Lilac Lavender (`#A78BFA`), Matcha Mint (`#34D399`), Buttercream Honey (`#FBBF24`), Sky Soda Blue (`#60A5FA`), dan Coral Candy (`#FB7185`).
      c) Geometri Empuk (Pillowy Radii): Sudut kartu dan modal melengkung lembut (`border-radius: 14px - 20px`), pill-shaped badges (`border-radius: 9999px`), dan tombol empuk.
      d) Taktil Neo-Brutalism: Garis luar pekat tinta gelap (`2px solid #1E1B4B`), hard offset drop shadow kenyal tanpa blur (`box-shadow: 2px 2px 0px #1E1B4B` atau `3px 3px 0px`), serta respon tekan mekanis (`active: translate(2px, 2px); box-shadow: none`).
      e) Tipografi Bersahabat Tanpa Emoji: Pasangkan font ramah modern (*Plus Jakarta Sans*) dengan font presisi teknis (*JetBrains Mono*). Gunakan kurung siku `[...]`, panah ASCII murni `[->]`, bullet solid `•`, dan chevron dropdown `[▼]`.
26. Mobile Brainstorming Architecture Tanpa Pangkas Fitur (Zero Feature Pruning & Bottom Thumb Zone):
    - Saat mengadaptasi antarmuka perancangan strategi, catatan, atau PRD dari desktop ke ponsel mobile:
      a) Haram Memangkas Fitur: Seluruh fitur (editor teks markdown, kompartemen coretan/scratchpad, AI architect chat, 4 tombol transformasi 1-klik PRD/Plan, selector model AI, pencarian, filter, sync vault) wajib 100% utuh dan siap pakai di ponsel.
      b) Bottom Navigation Dock (Thumb Zone Hoober): Bilah navigasi modul utama (`[CATATAN]`, `[EDITOR]`, `[CORETAN]`, `[AI MIKIR]`) wajib diletakkan paten di bagian bawah layar ponsel (`position: fixed; bottom: 0; left: 0; right: 0;`). Menaruh segmented control di bagian atas layar adalah anti-pola ergonomi yang memicu kelelahan ibu jari (*finger gymnastics*) dan memangkas area baca vertikal.
      c) Single-View 100% Viewport Width: Pecah layout multi-kolom horizontal desktop menjadi tampilan mandiri 100% lebar layar per tab aktif. Area penulisan editor harus mendapatkan ruang vertikal penuh tanpa terpotong laci permanen.
      d) Dedicated Scratchpad Paper: Sediakan ruang corat-coret terpisah berlatar warna kertas hangat (Buttercream/Warm Custard) untuk menampung ide spontan sebelum dirapikan, lengkap dengan tombol 1-klik `[-> PINDAHKAN CORETAN KE EDITOR]`.
      e) Floating Action Pill: Pasang tombol aksi cepat (seperti `[BEDAH PRD]` atau `[TANYA AI]`) yang mengambang di jangkauan ibu jari sehingga pengguna dapat memicu AI langsung saat membaca naskah tanpa berpindah-pindah layar secara manual.
27. Pola Pengelompokan Kontrol Mobile (Dropdown Grouping Pattern untuk Antarmuka Padat Fitur):
    - "Jangan pangkas fitur di mobile" bukan berarti menumpuk semua tombol aksi secara terbuka di layar ponsel yang sempit.
    - Kumpulkan kontrol sekunder (Export .md/.txt, Cetak/PDF, Salin Teks, Masukkan Berkas, Vault Sync, Template) ke dalam satu menu dropdown taktil (`[AKSI ▼]`).
    - Untuk transformasi AI multi-opsi (seperti Bedah PRD, Action Plan, Action Items, Critic), padatkan 4 tombol besar menjadi satu dropdown pintar (`[TRANSFORMASI DRAF ▼]`). Ini membebaskan >60% tinggi layar vertikal untuk area pengetikan dan pembacaan.
28. Pemisahan Jalur Metadata & Toolbar Format Teks (Anti-Offset Metadata Pitfall pada Layar Sempit 390px):
    - Pitfall: DILARANG menaruh elemen status/metadata dengan `margin-left: auto` di dalam kontainer flex horizontal yang memiliki `overflow-x: auto`. Jalur scroll horizontal akan mendorong elemen status keluar ke ujung kanan track scroll tak terlihat.
    - Solusi: Pisahkan elemen metadata/statistik dokumen (jumlah kata, karakter, estimasi waktu baca) ke baris non-scrolling (misalnya sejajar dengan selector kategori). Biarkan toolbar format teks murni menampung tombol aksi.
    - Presisi Viewport 390px: Pada layar smartphone, gunakan singkatan tombol yang ringkas dan padat (`[B]`, `[I]`, `[H1]`, `[H2]`, `[LIST]`, `[CHK]`, `[TBL]`, `[CODE]`, `[QTE]`) dengan padding terkalibrasi (`2px 4.5px`) dan atribut `title` tooltip deskriptif agar seluruh 9 kontrol muat rapi dalam satu baris tanpa terpotong (*zero clipping*).
29. Aksi Taktil 1-Klik Salin (Direct Copy Action) pada Balasan AI Mobile:
    - Setiap gelembung respons AI pada tampilan mobile wajib menyertakan tombol `[SALIN]` berdampingan dengan tombol injeksi dokumen (`[-> KE EDITOR]`, `[+ SAMBUNGKAN]`), memberikan kemudahan menyalin teks ke clipboard tanpa hambatan seleksi teks manual pada layar sentuh.
30. Doktrin Penanganan Skor < 5 & Ground-Up Pivot (Doktrin 059, 063, 066, 077):
    - Skor < 5 Adalah Kegagalan Total: Jika pengguna memberi nilai di bawah 5 (seperti skor Struktur Anti-AI Slop 2, Animasi 4, atau Copywriting 5), pekerjaan dianggap gagal total. Dilarang keras hanya memoles draf yang salah atau menambal kosmetik/warna sedikit.
    - Hancurkan Template AI SaaS Klise: Jangan pertahankan struktur generik AI (badge melayang -> headline bertumpuk -> 3 kartu pilar sejajar -> simulator kotak -> slider ROI mainan -> 3 kartu harga -> form). Buang total dan bangun ulang dari nol (*ground-up pivot*).
    - Arsitektur Living Flight Deck & Swiss Tabular Ledger: Gantikan struktur klise dengan (1) Living Autonomous Flight Deck berbasis data riil, (2) Fisika Pegas 60 FPS (Hooke's Law: $F = -kx - cv$) pada kanvas graf interaktif, dan (3) Swiss Archival Ledger (SPEC-01 s/d SPEC-04) horizontal baris-demi-baris dengan metrik invarian kanan, chip spesifikasi, dan zero card-nesting.
31. Eliminasi Deterministik 10 Tell AI-Slop (Standar Craft Floor Impeccable & WCAG AA):
    - 1) Cream/Beige Reflex Banned: Menjadikan latar warm cream/beige (#efece6) sebagai default refleks adalah tell AI-slop. Gunakan kertas mineral bersih (#F4F5F7 / #F8FAFC) atau palet yang dipilih sengaja.
    - 2) Kicker Above Heading Banned: Dilarang membuat label uppercase kecil ber-tracking lebar tepat di atas heading. Heading harus berdiri sendiri dengan bobotnya.
    - 3) Nested Cards Banned: Kartu di dalam kartu (card inside card) memicu visual noise dan kedalaman artifisial. Flatten hierarki menggunakan divider 1px, tabular grid, atau micro-callout.
    - 4) Dark Glow Shadow Banned: Colored box-shadow halo (#ff5c00 blur) pada background gelap adalah gaya AI murahan. Gunakan neutral elevation shadow murni (rgba(0,0,0,0.06)).
    - 5) Pulsing Liveness Dot Banned: Titik pulsing dot tanpa telemetri riil mensimulasikan keaktifan palsu. Gunakan static status badge yang jujur dan tenang.
    - 6) Layout Thrash Transition Banned: Animasi transition: width memicu layout thrash. Wajib gunakan transform: scaleX(...) dengan transform-origin: left.
    - 7) Skipped Heading Hierarchy Banned: Jangan melompati heading (misal h1 langsung ke h3 tanpa h2).
    - 8) Excessive Line Length Banned: Kunci batas baca maksimal max-width: 58ch hingga 65ch agar teks tidak melebihi 80 karakter per baris.
    - 9) Button Contrast Ratio Invariant: Teks putih di atas Safety Orange (#FF5C00 / #EA580C) gagal WCAG AA (3.55:1). Gunakan teks obsidian gelap (#0F172A) di atas Safety Orange untuk rasio kontras 8.5:1 bergaya instrumen industrial Swiss.
    - 10) Undersized UI Text Floor: Seluruh teks fungsional interaktif (navigasi, tombol, tag, sel tabel, baris meta, timecode) wajib minimal 11.5px–12px. Teks fungsional di bawah 11px adalah kegagalan legibilitas nyata.
32. Standar Otorisasi Rilis Konten Otonom (Autonomous QC Gatekeeper Invariant):
    - Jangan menahan rilis konten otomatis pada antrean persetujuan manual (tombol Telegram). Serahkan wewenang rilis penuh ke Agent QC (Invariant Auditor).
    - Ambang Batas: Skor QC >= 80 langsung terbit otomatis ke media sosial (Instagram/TikTok). Skor < 80 atau pelanggaran foto guard otomatis dibatalkan di tempat (HARD_VETO). Telegram hanya digunakan untuk warta hasil publikasi bersih tanpa interupsi tombol.
33. Otomasi Desain Figma Desktop Lokal (`creative/figma-cli`):
    - Saat pengguna menghendaki pengerjaan langsung di Figma, gunakan skill `creative/figma-cli` yang berkomunikasi via CDP port 9222 secara lokal tanpa cloud API key dan tanpa kuota.
    - Alur: `figma-cli connect` (Yolo/Browser/Safe mode) -> `render-batch` untuk komponen/layout JSX -> `blocks create dashboard-01` untuk template dasbor cepat -> `tokens preset shadcn` untuk koleksi variabel warna -> verifikasi visual via `figma-cli verify "<id>" --measure`.
34. Dedicated Standalone Page vs Inner Tab/Menu (Permintaan "Page Baru" Wajib Halaman Mandiri Penuh):
    - Pitfall: Ketika pengguna meminta "bikin page login / page baru / halaman otorisasi", DILARANG membungkusnya sebagai tab menu internal (misal: `view-login` di dalam sidebar navigasi aplikasi kasir/dasbor). Itu merusak ergonomi ("masak seperti menu") dan membingungkan operator.
    - Solusi Arsitektural: Wajib dibuat sebagai berkas/halaman mandiri terpisah penuh (`login.html` atau rute terisolasi) tanpa chrome bilah sisi (sidebar) atau viewport dasbor di sekelilingnya.
    - Sasis Mandiri: (1) Halaman berdiri bebas dengan header global minimalis (identitas usaha, jam live, status koneksi server), (2) Tata letak split-stage card terpusat (panel branding & konteks operasional di satu sisi, formulir interaktif di sisi lain), (3) Fitur cepat tanpa validasi pemblokir (`novalidate`, 1-klik profil demo kasir/admin, auto-redirect kembali ke dasbor utama setelah otorisasi tersimpan di storage), (4) Tautan navigasi timbal-balik yang tegas (`Kembali Langsung ke Dashboard Kasir` pada halaman login, dan tombol navigasi eksplisit `Halaman Login (Page Baru)` pada footer profil kasir dasbor utama).
