# Claim-proof ledger
Before reporting technical work, enumerate user-visible claims and map each to a test ID and concrete observation. Local tests, HTTP status, browser behavior, and provider end-to-end checks are different evidence classes. Create a non-sensitive task record and run `terminal(command="python3 /home/ubuntu/agent-quality/quality_gate.py <record.json>")`. Qualify or remove claims without passing checks. A returned iframe URL is not proof of actual playback; preview is not rendered MP4. Report limitations plainly.
