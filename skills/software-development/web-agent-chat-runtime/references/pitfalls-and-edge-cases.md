## Pitfalls

- **The Missing `stop_reason` State Machine Pitfall**: Treating LLM streaming responses purely as string concatenation without tracking the reason generation terminated (`end_turn`, `tool_use`, `max_tokens`) breaks autonomous tool execution and continuation handling. Always normalize upstream gateway finish reasons into explicit `stop_reason` states.
- **The Unstructured Context Bleed Pitfall**: Dumping system instructions, developer personas, user memories, and uploaded document text into flat concatenated strings causes instruction cross-contamination and prompt injection vulnerabilities. Use explicit XML demarcation tags (`<system_instructions>`, `<user_memories>`, `<attached_documents>`) to maintain clean contextual boundaries.
- **The Empty-Password Admin Authentication Bypass Trap**: In 1-step or passwordless registration routes, checking `if (user.password_hash && password)` allows attackers to bypass password verification by simply submitting an empty password string (`password = ''`), granting unauthenticated access to existing accounts. Always enforce strict password verification for privileged roles (`admin`, `master`) regardless of input presence (`if (isAdmin && (!password || !password.trim())) throw new Error(...)`).
- **The Unbounded Streaming Concurrency Saturation Trap**: Exposing SSE completion endpoints without concurrency bounds allows automated scripts or concurrent user tabs to trigger dozens of parallel inference streams, exhausting local GPU/CPU VRAM and causing 60-second timeouts. Enforce per-user ($\le 2$) and global ($\le 6$) active stream bounds with HTTP 429/503 responses.
- **The Stale Guest Account Bloat Trap**: Offering 1-click "Masuk sebagai Tamu" accounts without automatic time-to-live (TTL) expiration causes thousands of ephemeral rows to accumulate in SQLite `users`, `conversations`, and `messages` tables over time. Implement a periodic garbage collection routine (`DELETE FROM users WHERE (role = 'guest' OR email LIKE 'tamu_%') AND last_login < datetime('now', '-7 days')`) using `.unref()` timers.
- **The Dummy Binary Attachment Trap**: Inserting dummy labels (`[Lampiran: file.pdf]`) into prompts without extracting text causes the LLM to hallucinate or apologize for not being able to read documents. Use server-side extraction (`pdf-parse`, `mammoth`) to embed actual text into the context payload.
- **Cross-Tab Quota Desynchronization Trap**: Updating user balances only within the active tab causes background tabs to display stale token balances until refreshed, leading to unexpected 402 quota-exhausted errors on subsequent prompts. Post balance updates to a `BroadcastChannel` to keep all open tabs synchronized.
- **The Node.js `req.on('close')` SSE Premature Abort Trap**: Binding an abort controller to `req.on('close', () => abortController.abort())` in a POST handler with a JSON body causes Node's incoming request stream to emit `'close'` as soon as the POST body finishes reading, instantly aborting outbound upstream LLM fetches before any chunks stream back. Always listen to client disconnection on `res.on('close', () => { if (!res.writableEnded) abortController.abort(); })`.
- **The Missing `[DONE]` Gateway Stream Hang Pitfall**: Many OpenAI-compatible model routers and gateways (e.g. 9Router, vLLM, local reverse proxies) terminate completion chunks with `finish_reason: "stop"` or `"end_turn"` without sending an explicit `data: [DONE]` marker, keeping the HTTP keep-alive connection open. An SSE chunk reader checking only `dataStr === '[DONE]'` hangs indefinitely until socket timeout. Always break the stream parser loop if `dataStr === '[DONE]' || parsed?.choices?.[0]?.finish_reason === 'stop' || parsed?.choices?.[0]?.finish_reason === 'end_turn'`.
- **The Dynamic SQL Re-compilation in SSE Routes Trap**: Preparing SQL statements inside request handlers or streaming callbacks forces SQLite to re-parse and compile the SQL query on every turn or chunk. Cache all prepared statements at service initialization (`stmts = { saveMsg: db.prepare(...), deduct: db.prepare(...) }`), and wrap multi-step quota mutations and message inserts inside `db.transaction(...)` for zero-overhead, crash-safe atomic consistency.
- **The Fragmented `<ol>` Number Reset Pitfall ("Nomor Urut 1 Terulang")**: Grouping numbered list lines (`\d+\. `) into `<ol><li>...</li></ol>` via single-line regex passes breaks when items contain multi-line descriptions or double newlines between steps. The parser matches each numbered line separately, wrapping each in an isolated `<ol>` element. The browser resets list numbering on every isolated `<ol>`, displaying `1.` on every single item in the UI. Either accumulate paragraph continuation lines into the active `<li>` container, or parse list numbers explicitly into structured elements with preserved index values.
- **The Mobile Scroll Inset & Dock Submersion Trap ("Ketutup Dock Bawah & Terpotong Atas")**: Sizing chat scroll containers with tight vertical padding under sticky mascot headers and above floating input docks causes double layout degradation: the top text line is clipped in half by the upper alpha fade mask when scrolled up, and the bottom conclusion or action buttons are submerged behind the floating dock capsule. Enforce `padding-top: max(32px, env(safe-area-inset-top) + 24px)` to clear upper gradient masks, and enforce `padding-bottom: calc(var(--dock-height, 120px) + 80px)` (at least `210px-240px` on mobile) so the lowest message clears the dock with comfortable breathing space.
- **Naïve RegEx List Splitting**: Splitting numbered lists with single-line regexes breaks multi-line explanations or indented paragraphs, ejecting the explanation out of the `<ol>` container. Use a tokenizer that accumulates continuation lines into the current list item.
- **Block Elements Inside `<p>`**: Wrapping raw markdown outputs in `<p>` causes browsers to prematurely terminate paragraphs on headers, lists, and code blocks, resulting in malformed DOM trees and collapsed margins.
- **The Bot Echo Trap**: Piping user chat inputs into outbound bot dispatchers (e.g. `hermes send --to telegram`) transmits the prompt under the bot's token credentials. In mirrored channels the prompt arrives as an agent message, and the agent's self-message filter drops it to prevent infinite loops, leaving the prompt unaddressed.
- **Mobile Multi-Line Placeholder Truncation**: Long placeholder text in compact mobile input capsules wraps onto a second line, causing vertical glyph clipping against container borders. Always enforce single-line placeholder styling with `white-space: nowrap; text-overflow: ellipsis;`.
- **The Inset Mobile Container Squeeze Trap ("Kolom Chat Sempit")**: Keeping desktop card margins (`left/right: 8px-16px`) and forcing side-by-side avatar rows on mobile restricts assistant reading width to $<300\text{px}$, creating a cramped receipt-like text column. On mobile ($\le 768\text{px}$), enforce full-bleed containerization (`left: 0; right: 0; border: none;`), stack the avatar above text or use an inline header, and expand the input field tap target to `min-height: 38px-42px; font-size: 15px;`.
- **The Tiny Slit Textarea Tap Target**: Setting mobile chat textareas to single-line 22px-26px heights creates an uncomfortable, cramped tap zone on touchscreens. Enforce `min-height: 38px-42px; font-size: 15px;` with `bottom: max(8px, env(safe-area-inset-bottom, 8px))` to maintain thumb comfort and prevent iOS viewport zoom.
- **Mobile Header Horizontal Overflow**: Retaining multi-word button labels and wide brand subtitles on small viewports inflates header `scrollWidth` past `100vw`, breaking page touch gestures. Collapse labels to icon-only buttons and hide secondary branding under $\le 640\text{px}$.
- **Modal Preview Collision with Sticky Footers**: Sticky action footers in mobile bottom sheets cover the bottom lines of prompt previews or code snippets unless `.modal-body` carries explicit `padding-bottom: calc(var(--footer-height) + env(safe-area-inset-bottom, 0px))`.
- **Gradient Bleed Confusion**: Using transparent gradients across the entire bottom dock allows background message text to show through interactive chip labels, causing visual collision and failing accessibility contrast standards.
- **Synchronous Promise Blocking**: Awaiting long-running LLM generation inside synchronous browser automation wrappers (`Runtime.evaluate` with `awaitPromise=true`) triggers helper IPC timeouts before the model returns. Decouple request execution from the event loop.
- **Untyped Message Roles**: Relying on string heuristic pattern matching instead of explicit `role` fields causes user prompts and agent responses to invert when messages are re-fetched from storage.
- **Full-Width Chat Bubble Bleed**: Allowing chat bubbles to span 100% width on mobile eliminates the visual distinction between sender and receiver. Restrict bubble wrappers to `82%-86%` max-width with opposite horizontal alignment.
- **Unresumed AudioContext Autoplay Failure**: Invoking Web Audio oscillator synthesis before the user's first click or touch event fails silently due to browser autoplay policies. Lazy-initialize or resume `AudioContext` within the pointer/touch handler before triggering tones.
- **Destructive Polling Reflow Loop ("Pseudo-Refresh")**: Blindly overwriting `container.innerHTML` on every polling interval without dirty-checking forces complete DOM teardown and repaint, mimicking an unprompted page reload every few seconds and unfocusing inputs. Always compute and compare a lightweight signature (`${messages.length}:${last.time}:${last.content.length}`) before updating the DOM.
- **The Scroll-Drowned Mascot**: Putting the mascot or companion avatar inside the scrollable message container causes it to scroll out of view when messages expand, creating the illusion that the mascot disappeared upon chatting. Keep companion stages as structural siblings outside the scroll container (`<main> > #companion-zone + #chat-stream`).
- **Kinematics Transform Clobbering (The Exploding Mascot Bug)**: Setting CSS classes like `.chat-mode { transform: scale(0.35); }` fails if a continuous `requestAnimationFrame` JavaScript loop writes `element.style.transform = 'translate3d(...) scale(1.0)'` on every frame. The inline style wins every tick, causing the full-size mascot head to escape small container bounds and occlude header navigation. Always manage base scale within the JS kinematics matrix.
- **Harsh Scroll Clipping at Sticky Boundaries**: Abruptly terminating scroll container bounds directly beneath floating headers causes half-rendered avatars and text lines to visually collide. Use CSS `-webkit-mask-image` linear gradient fading at the top edge of the scroll area.
- **Scroll Fade-Mask Top Inset Collision**: Applying a top linear gradient mask to a scroll container (`-webkit-mask-image: linear-gradient(to bottom, transparent 0px, black 14px, ...)`) clips the top pixels of the first message or card if container `padding-top` $\le$ the fade distance. Always set container `padding-top` strictly greater than the mask fade threshold (e.g. $\ge 20\text{px}$ for a 14px fade mask) so initial messages never start inside the transparent fade boundary.
- **The Shrunken Badge & Cluttered Status Pill Trap**: Compressing the mascot into a 32px badge alongside an explanatory text pill cramps the mobile screen, creates awkward visual competition with message bubbles, and robs the character of its expressive charm. Keep the mascot large in the corner with an ambient transparent gradient and eliminate the side text bar completely.
- **Hard Border Cuts on Ambient Gradients**: Adding 1px bottom or side borders to an ambient companion gradient ruins the illusion of a seamless organic atmosphere and leaves sharp visible seams against the chat stream. Enforce `border: none !important; border-bottom: none !important;`.
- **The Upward Rig Drift ('Molor ke Atas') & Negative Headroom Trap**: Scaling up a centered 3D/CSS mascot in a corner stage expands the character equally upwards and downwards. Without a downward transform offset (`chatOffsetY`) and damped vertical hover amplitude, the mascot's antenna or head apex drifts upwards and collides with or overlaps the top header border (`rigTop < headerBottom`), creating a visually cramped, stretched feeling ("molor ke atas"). Always introduce a downward vertical offset and verify positive headroom clearance ($\ge 6\text{px}-10\text{px}$) against the sticky header.
- **The "Lonjong" Mascot Egg Proportion Pitfall**: Setting mascot container height greater than width with an asymmetric egg-shaped border-radius and vertical harmonic breathing makes the mascot look oblong, rigid, and awkwardly stretched ("terlalu lonjong"). Enforce squircle/chubby dimensions where width >= height (e.g. 136×124px) with symmetric 48%–50% curvature and lateral breathing expansion.
- **The Character Scroll Drift Trap**: In Character-as-Container architectures, letting the outer character body or facial elements scroll along with the chat messages breaks the physical container illusion and causes the mascot's eyes to disappear off the screen. Keep the character card and face strictly pinned (`position: absolute; overflow: visible;`) and let only `#chat-stream` scroll (`flex: 1; overflow-y: auto; overflow-x: hidden;`), ensuring the character's body remains completely static during scrolling ("waktu gilir ke atas atau bawah itu ngga ngikut tubuhnya").
- **The Living Container Appendage Clipping Pitfall**: Applying `overflow: hidden;` to the outer living body container card (`#mumu-living-container`) chops off 3D claymorphic ears, antenna spheres, or crests peeking over the top rim into the background canvas. Always enforce `overflow: visible;` on the parent container and restrict `overflow-y: auto; overflow-x: hidden;` exclusively to the nested chat stream container.
- **Mascot Visor Toast Collision**: Positioning floating system toasts at `top: 70px-80px` on mobile places the notification directly across the mascot's eyes and visor, destroying the illusion of a living character. Anchor floating toasts either above the header or suspended above the bottom input dock (`bottom: ~140px`).
- **Lifeless Flat-Tab Ear Anatomy**: Rendering mascot ears as flat rounded rectangular tabs makes them appear like detached UI stickers rather than cohesive 3D physical parts of the character. Use dual-layer claymorphism with an outer volumetric shell and an inset `::after` conch cavity with subtle inner drop shadow.
- **Detached Floating Ear & Static Appendage Pitfall**: Floating mascot ear pods without structural grounding sockets look disconnected and awkward, especially on mobile. Leaving ears completely static breaks the illusion of a living character. Anchor ears with snug base sockets and equip them with multi-state kinetic rigging (organic idle sway, spontaneous listening twitches, thinking radar sweep, and interactive tap-reaction spring pops).
- **Backend Model Suffix Leakage**: Leaking internal backend provider codenames or model suffixes (e.g. `Mumu bk`) into consumer-facing dock pills and status labels adds unnecessary cognitive friction. Keep user-facing model labels cleanly simplified to the core persona identity (`Mumu`).
- **Unparsed Markdown Tables**: Omitting table parsing from markdown formatters displays raw pipe characters and column markers (`|:---|:---|`), creating visual clutter in technical responses. Always detect and compile pipe blocks into semantic, responsive HTML tables.
- **Duplicate Reset Affordance Clutter**: Stacking duplicate "New Chat" buttons in both the fixed header and an in-stream companion bar wastes vertical screen real estate on mobile and truncates companion status text. Keep the global reset button strictly in the top header.
- **Template Card & Tag Button Clutter Pitfall**: Overfilling empty state canvases with multi-paragraph prompt cards, tag buttons, and complex crafters overwhelms the user and feels unrefined compared to premier LLMs like Claude or ChatGPT. Keep empty states serene and zen with concise copy.
- **Missing Generation Abort (Stop Mode)**: Omitting a stop generation mechanism leaves users helpless when an LLM begins generating verbose unwanted output. Always morph the send button into a high-contrast square stop button (`■`) wired to `AbortController.abort()`.
- **Monolithic Frontend Code Sprawl**: Accumulating unused modal templates, obsolete preset blobs, and duplicate CSS overrides inflates frontend files past 3,000 lines, slowing down DOM parsing and developer iteration. Refactor aggressively to keep components modular, clean, and under 1,500 lines.
- **Unstyled Code Copy Failure**: Rendering code blocks without copy affordance forces users to manually select and drag text on mobile screens. Always provide a distinct code block header with language badge and an animated one-click copy button.
- **The Living Container Negative Headroom Trap ("Terlalu ke Atas")**: Setting container `top: 50px` on mobile directly crushes the container against the top navbar (height 52px), crowding the mascot's head against the screen ceiling and causing unclipped appendages to collide with header dropdowns. Always enforce container `top >= 80px-86px` on mobile (desktop `top >= 76px`) to ensure $\ge 30\text{px}$ of clear open headroom.
- **The Flat Solid Dot Happy Eye Illusion**: Rendering joyful/happy companion eyes as solid oval or rectangular dots fails at mobile scale, looking identical to neutral or alert eyes. Construct upward-curving crescent arches with top/left/right border outlines and neon bloom (`border-top: 3.5px solid #00e5ff; border-left: 2px solid #00e5ff; border-right: 2px solid #00e5ff; border-bottom: none; border-radius: 14px 14px 0 0; background: transparent;`).
- **The Dead Solid Card vs Frosted Morphic Glass Contrast**: Using 100% opaque flat white fills for large container cards deprives the interface of dimensional atmosphere and visual luxury. Use frosted glassmorphism (`backdrop-filter: blur(24px-28px) saturate(200%)`, translucent white fills, specular rim borders) over drifting ambient glow mesh orbs to produce vibrant refractive depth.
- **The Unicode Emoji Slop Pitfall**: Using Unicode emojis (`✨`, `🐴`, `●`, `✦`, `👍`) across titles, buttons, toasts, and headers destroys the premium, high-end Apple iOS aesthetic and makes the UI feel amateurish. Strictly use clean, sharp inline SVG vector glyphs modeled after SF Symbols.
- **The Full-Screen Settings Modal Trap**: Presenting simple settings as a giant full-screen modal breaks chat context and feels clunky on both desktop and mobile. Mount a compact top-right dropdown popover with horizontal sliding submenus (`‹ Kembali`) for nested configuration.
- **Header Model Picker Disconnection**: Placing model and reasoning controls in the distant top navigation bar disconnects them from the prompt input context. Position model and thinking effort pills directly inside the bottom input dock capsule (like ChatGPT).
- **Mobile Virtual Keyboard Occlusion**: Relying solely on `100dvh` or `env(safe-area-inset-bottom)` leaves floating input capsules hidden beneath or floating awkwardly above mobile software keyboards. Always bind `window.visualViewport` `resize` and `scroll` events to dynamically offset `bottom`.
- **Harsh Blur Cutoff Seams**: Abruptly terminating backdrop-filter containers creates jarring horizontal boundary lines. Always feather blur edges using linear opacity gradient masks (`-webkit-mask-image`).
- **Ambiguous Token Count Confusion**: Displaying bare token numbers (e.g. `~76 token`) confuses users into thinking it represents word or sentence counts. Explicitly qualify as API compute tokens with cost estimates (`45 token • Biaya: $0.0001`).
- **The Flat Dark Navy Prompt Bubble Discordance**: Styling user prompt bubbles with flat, heavy dark navy fills on light-mode or pastel gradient canvases creates a gloomy, jarring visual weight that clashes with playful companion aesthetics. Use a harmonious, luminous multi-stop blue gradient (`#3b82f6` $\to$ `#1e40af`) with specular rim lighting and soft colored ambient drop-shadow.
- **Hidden Automation Schedules Trap**: Burying or omitting background cron automation jobs from settings leaves users blind to background system operations. Expose active cron jobs directly inside a dedicated Skedul submenu.
- **Redundant Dropdown Selection Toasts Trap ("Notif Seperti Ini Ngga Perlu Ada")**: Firing floating toast notifications when the user toggles a model or reasoning effort pill in the input dock adds annoying visual clutter because the pill button text already updates directly under their thumb. On mobile, top-center toasts (`top: 64px-75px`) directly collide with and mask the character mascot's face. Reserve toasts strictly for substantive actions that lack immediate inline feedback (e.g. "Pesan tersalin", "Instruksi disimpan"), and pin them safely to extreme perimeters (`top: 14px` or `bottom: 90px`).
- **Code Block Child Inheritance Clutter (`.message-bubble code`)**: Styling inline code broadly using `.message-bubble code` causes `<pre><code>` inside code block wrappers to inherit background color, padding, and borders, rendering ugly light patches behind every line of code. Always scope inline code using child exclusions (`.message-bubble :not(pre) > code`) and explicitly reset `.code-block-wrapper pre code` to `background: transparent !important; border: none !important; padding: 0 !important; color: #0f2b48 !important;`.
- **HTML Entity Collision in Syntax Highlighting**: Running syntax highlighting regex on pre-escaped HTML breaks string matching (quotes become `&quot;` or `&#039;`), while digit regexes (`\b(\d+)\b`) match and corrupt numeric character references like `&#039;` into `&#<span class="tok-number">039</span>;`, and comment regexes matching `#` treat `&#039;` as Python comments. Extract fenced code blocks with placeholders BEFORE general escaping, tokenize syntax with collision-free token delimiters (`___TKN_n_END___`), escape non-token code fragments, and re-inject safely.
- **The Monochromatic Markup Pitfall**: Restricting syntax highlighting regex solely to JS/Python keywords leaves HTML, XML, SVG, and CSS blocks completely unhighlighted as flat, monochromatic text on light backgrounds. Always include regex passes for HTML tags (`<tag`), attributes (`attr=`), attribute values (`"..."`), and doctypes.
- **Nested Syntax Token Recursion Trap**: When string tokens reside inside HTML attribute replacements, running a single replacement pass leaves unexpanded tokens (`___TKN_n_END___`) inside the rendered code. Use a bounded recursive `while (code.includes('___TKN_') && safety < 10)` loop to fully unwrap nested tokens safely.
- **Modal Header Action Crowding on Mobile**: Stacking multiple textual buttons (e.g. "Mobile", "Desktop", "Tab Baru", "Tutup") in a modal header compresses the title and forces vertical line wrapping on narrow viewports ($\le 390\text{px}$). Enforce `white-space: nowrap; text-overflow: ellipsis;` on titles and hide button text spans under mobile media queries to preserve a compact icon-only toolbar.
- **Layout Linter False-Positive on Media Viewers**: Naming image or lightbox containers with substring keywords like `card`, `box`, `panel`, or `tile` triggers layout audit rules (`EMPTY_DECORATIVE_SLOP`) when the container holds only an image element without text. Name media containers semantically (e.g. `.image-viewer-stage`) to avoid false-positive linter failures.
- **Cross-Origin Anchor Download Failure**: Relying solely on `<a href="url" download>` to download external images generated via CDN or API links fails to trigger a file download dialog in modern browsers due to same-origin restrictions, silently opening the image in a new tab instead. Use an asynchronous `fetch()` with `mode: 'cors'`, convert to a Blob, generate an ephemeral object URL (`URL.createObjectURL(blob)`), and click an programmatic anchor tag.
- **Inline Onclick Quote Breaking on Dynamic Media**: Concatenating unescaped URLs or markdown image alt captions into inline `onclick="fn('url', 'caption')"` templates causes immediate JavaScript syntax errors when captions contain single quotes, apostrophes, or query parameters. Always bind URLs and captions via HTML `data-*` attributes (`data-url="..."`) and read them via `element.dataset`.
- **Forced Synchronous Layout Thrashing in Animation Loops ("Animasi Berat / Patah-Patah")**: Never query geometric DOM properties (`getBoundingClientRect()`, `offsetWidth`, `clientHeight`) inside a 60/120 FPS `requestAnimationFrame` loop. Querying layout geometry while simultaneously mutating transforms or styles forces the browser engine into synchronous reflows on every frame, generating sluggish, heavy animation ("animasi berat"). Always cache anchor coordinates outside the rAF loop, and recalculate strictly on passive window `resize` or `scroll` listeners.
- **Sub-Pixel Dead-Zone DOM Style Write Clamping**: Continuously writing to `element.style.transform` on every animation tick even when coordinates or spring scales have converged keeps browser style recalculation pipelines busy and causes subtle micro-jitter. Gate DOM style writes behind an explicit perceptual delta threshold (e.g. eye movement $> 0.01\text{px}$, sheen $> 0.8\%$), and halt updates when resting.
- **Missing GPU Hardware Layer Promotion**: Animated elements with box-shadows, blurs, or border-radius curves must have `will-change: transform`, `transform: translateZ(0)`, and `-webkit-backface-visibility: hidden` so rotations/translations stay on dedicated GPU compositor textures without repainting the parent layer.
- **Featherlight Composite-Only Keyframes (No `filter: blur` in Transitions)**: Never animate `filter: blur(...)` during streaming text reveals or entry transitions; blur animation triggers expensive off-screen GPU framebuffer passes per frame. Restrict entry animations to composite-only properties (`transform: translateY(...)` and `opacity`) for smooth 120 FPS.
- **The Floating Dock Content Occlusion Pitfall ("Ketutup Dock Bawah")**: Sizing chat stream bottom padding to match only the dock's raw height leaves the bottom-most media cards, image captions, or token badges hidden behind the dock's backdrop blur and opacity mask. Always pad the scroll container with at least `dock_height + 60px` (e.g. `180px-185px` on mobile) to guarantee total clearance.
- **The Raw LaTeX Equation Slop Trap**: Outputting mathematical models, Little's Law queues, or Greek notations without mathematical typesetting leaves raw LaTeX markup (`$$...$$` or `$ ... $`) exposed in editorial prose, looking unpolished. Always extract display and inline math into placeholders before general HTML escaping, compile with KaTeX (`katex.renderToString()`), and bundle vendor assets locally for zero-latency offline rendering.
- **The Session Proliferation & Duplicate Regenerate Bubble Trap**: Generating a new session ID timestamp on every turn in an active thread fragments conversations across duplicate entries in the history drawer. Track an `activeSessionId` across multi-turn exchanges to update existing session records. On "Buat Ulang" (regenerate response), pop the last assistant response from DOM and conversation state; do NOT re-append a duplicate user prompt bubble.
- **The Naïve Multi-Turn Regeneration Trap ("Buat Ulang Meregenerasi Prompt yang Salah")**: Calling a parameterless `regenerateLastResponse()` that blindly reads the last user turn from state causes regeneration of earlier assistant cards in multi-turn dialogues to erroneously re-send the *latest* prompt instead of the prompt that actually generated that card, desynchronizing conversational context. Always pass `this` to locate the target assistant card's preceding user row, prune downstream DOM elements and state, and regenerate that specific turn in-place.
- **Session History Title Metadata Pollution Trap**: Slicing raw prompt strings for history titles without stripping prepended system or context instructions (`[Konteks Pengguna: ...]`, `[Gaya Respon: ...]`) pollutes the history drawer with repetitive configuration prefixes instead of displaying the user's authentic question. Always sanitize prompts with regex before extracting title substrings.
- **The Ignored Backend Thinking Parameter Trap**: Mounting reasoning effort controls in the input dock without forwarding `thinking` across the HTTP boundary leaves reasoning modes dead. Forward `thinking`, calibrate temperatures and token ceilings, and adapt system personas between direct solutions (`off`) and formal causal mathematical decompositions (`deep`).
- **The Headless / Iframe Clipboard Rejection Failure**: Relying solely on `navigator.clipboard.writeText()` throws `NotAllowedError` in iframes, headless browser environments, or unfocused windows. Always catch rejections and fall back to programmatic `<textarea>` selection with `document.execCommand('copy')`.
- **The Dummy File Attachment String Trap**: Inserting dummy strings (`[Lampiran: file.js]`) into the input textarea without ingesting file contents breaks user expectations for document or code analysis. Use `FileReader.readAsText()` to embed source text into markdown code blocks with proper language syntax tags.
- **The Iframe-Only Artifact Sandbox Trap**: Rendering live HTML/SVG artifacts solely inside an `<iframe>` prevents developers from inspecting, tweaking, or copying source code directly from within the sandbox modal. Provide a segmented view toggle (`[Pratinjau] [Kode]`) with dark-theme syntax highlighting, hiding viewport size controls when in the code tab, and offering a 1-click source code copy affordance.
- **The Stiff Mobile Keyboard Scroll Displacement Pitfall**: Pinning the floating input dock to `visualViewport` without scrolling the active chat feed leaves the message context submerged behind the virtual keyboard while typing. On viewport shrinkage (`offsetFromBottom > 30px`), pin the dock bottom and trigger `chatStream.scrollTo({ top: chatStream.scrollHeight, behavior: 'smooth' })`, resetting `bottom = ''` on close to cleanly restore CSS `env(safe-area-inset-bottom)`.
- **The Mascot Antenna Header Crowding Pitfall**: Sizing the container top offset without factoring in protruding appendages (antennae, ears, crowns) leaves $<15\text{px}$ of clearance between the top navbar baseline and the mascot apex, creating severe visual crowding. Always guarantee $\ge 24\text{px}-32\text{px}$ of negative space (e.g. desktop container `top: 104px-108px`, mobile `top: 84px-86px`) so the header title and character both have room to breathe.
- **Silent File Download Feedback Pitfall**: Triggering Blob downloads without mutating the button's inline visual state leaves users clicking repeatedly in the belief that the action stalled. Always transform the export button to an emerald checkmark (`#10b981`) and confirmation label ("Diunduh") for 1.8s, accompanied by audio and haptic cues.
- **Missing Universal Keyboard Shortcuts Friction**: Lacking standard shortcuts like `Cmd/Ctrl+K` (focus prompt input), `Cmd/Ctrl+Shift+O` (new chat), and `Escape` (dismiss active popovers and overlays) introduces unnecessary pointer friction for power users.
- **Global Disk State Context Contamination Trap**: Slicing the last turns from a single server-wide chat log file for multi-turn inference causes different chat sessions and newly initialized threads to inherit dialogue history from previous unrelated exchanges. Always transmit and prioritize the frontend session's active dialogue context (`context: currentConversation.slice(-8)`).
- **The Speculative Hallucination on Server Telemetry**: Allowing an LLM to guess memory usage or service status when asked about server health leads to fabricated stats or generic terminal command regurgitation. Synchronously inspect live system metrics and inject verified data directly into the system context.
- **The "@" Persona Selector Mismatch**: Checking `lower.includes('@architect')` while the UI dropdown sends `agent: 'architect'` silently drops the persona selection, falling back to the default general assistant. Always normalize both tag identifiers and text mentions (`agentTag === 'architect' || lower.includes('@architect')`).
- **Monolithic XML Suppression of SVG Previews**: Restricting live preview buttons strictly to `cleanLang === 'svg'` leaves SVG diagrams wrapped inside `xml` code blocks unviewable in the artifact sandbox. Check `cleanLang === 'svg' || (cleanLang === 'xml' && code.includes('<svg'))`.
- **The Blocking LLM Wait Trap ("Loading Lama Tanpa Progres")**: Forcing users to stare at a static loading indicator for 5–10 seconds while the model generates its entire answer creates high perceived latency and uncertainty. Always implement native SSE token streaming (`text/event-stream`) to reduce Time-to-First-Token (TTFT) to under 1 second.
- **Chunk Fragmentation JSON Parse Crash**: Assuming every SSE event chunk delivers a single complete, well-formed JSON line causes `JSON.parse` syntax crashes when network TCP packets split a payload across packet boundaries. Always buffer stream chunks, split by newline (`buffer.split('\n')`), and retain the uncompleted trailing string in the buffer for the next iteration.
- **The Aborted Stream UI Crash Pitfall**: Catching `AbortError` from user cancellation with generic network error handlers renders an ugly red failure banner across the chat. When `err.name === 'AbortError'`, suppress error banners, preserve the partially received text bubble, and reveal standard action buttons (Salin, Buat Ulang) immediately.
- **Aggressive Streaming Scroll-Snapping Pitfall**: Unconditionally executing `chatStream.scrollTop = chatStream.scrollHeight` on every streaming chunk forcibly snatches the viewport down when users try to scroll up to inspect previous answers during live generation. Always guard auto-scroll behind proximity checks (`isNearBottom < 120px`).
- **The Streaming Code Block Layout Shift (CLS) Pop Trap**: Omitting odd-parity backtick auto-closure in markdown streaming parsers leaves code blocks rendered as raw unformatted text until generation finishes, abruptly jarring the reader with sudden card reflow when triple backticks finally arrive. Check odd backtick parity and auto-close parse buffers on the fly.
- **The Aborted Stream UI Limbo Trap**: Merely catching `AbortError` without calling `streamingRow.finish()` leaves the `.typing-cursor` blinking indefinitely, keeps action buttons hidden, and discards partial output from conversation state and storage. Finalize the active row immediately on abort with the partial text preserved.
- **The Unchecked Accidental Session Deletion Trap**: Binding raw click-to-delete handlers directly to history list item trash icons without tap confirmation causes accidental thumb taps on narrow mobile touch targets to permanently destroy multi-turn sessions. Always require two-step inline confirmation or verification toasts before purging records.
- **Generic Code Download Naming Pitfall**: Defaulting code file downloads indiscriminately to static generic filenames (e.g. `mumu-script.js` or `script.py`) forces users to manually rename every saved file. Always inspect the first line of the code block for file comment headers (`// server.js`, `# run.py`, `<!-- index.html -->`) to extract and apply the contextual filename automatically.
- **The Single Paperclip / Raw Attachment Dump Trap**: Using a single ambiguous paperclip button or dumping raw file text directly into the prompt textarea overwhelms the input box, disrupts prompt typing, and prevents users from cleanly managing or removing attachments. Provide dedicated Photo and Document triggers, surface visual preview chips with remove buttons in an attachment tray, and defer prompt structuring to dispatch time.
- **The Clipboard Screenshot Rejection Trap**: Omitting a `paste` event handler on chat textareas forces users to save screenshots to local disk before opening a file picker, introducing major friction during visual QA and bug reporting. Intercept `clipboardData.items` for `image/*` files and ingest directly into the attachment tray.
