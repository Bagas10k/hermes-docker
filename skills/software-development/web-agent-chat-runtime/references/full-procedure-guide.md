## Procedure

1. **Establish Identity, Persistence & Message Schema**:
   Freeze the authenticated room/session/message contract before UI work. Reuse the native agent's canonical transcript and distinguish stored-session IDs from live runtime IDs; keep only app-specific room mappings, reply references and idempotency state in the adapter. Do not create a competing transcript store by default. Bind messages and event cursors to principal, room and session. Coalesce native completion aliases by durable message ID and preserve unchanged message DOM nodes when reconciling history; duplicate `message.complete`/`turn.complete` fetches or unconditional replaceChildren can detach a preview/reply button between pointer-down and click.

2. **Submit Through the Authorized Agent Runtime**:
   - Send web prompts through the native agent protocol with server-checked session ownership and a payload-bound idempotency key; preserve tools, skills, memory, approvals and delegation. A plain completions call is not an equivalent agent backend.
   - Keep inbound user prompts separate from outbound messaging tools. Never broadcast a raw prompt to a bot channel to make the web chat run. Mirror external messages only when explicitly requested, with verified destinations and sender attribution.

3. **Implement Floating Prompt Dock & Anti-Bleed Layout**:
   - Position floating dock capsules with backdrop blur and high-opacity gradient backing (`linear-gradient(180deg, rgba(..., 0) 0%, rgba(..., 0.85) 15%, #... 40%, #... 100%)`).
   - Calculate container bottom padding strictly exceeding dock height plus gradient threshold: `padding-bottom: calc(var(--dock-height) + 40px);`. This prevents bottom chat bubbles from bleeding behind interactive chips or input textareas.

5. **Format Markdown, Numbered Lists & Paragraphs Safely**:
   - Stash fenced code blocks (` ``` `) with placeholder tokens (`@@CODEBLOCK_n@@`) before text parsing to preserve indentation, newlines, hashes, and symbols intact.
   - **Stateful Line-by-Line List Tokenizer (Anti-1-Reset Invariant)**:
     - When LLMs output loose ordered lists where numbered items contain explanatory paragraphs on subsequent lines (`1. **Judul**\nPenjelasan...\n\n2. **Judul**\nPenjelasan...`), single-line regex passes (`(?:<oli>[\s\S]*?<\/oli>\s*)+`) break completely. Because the non-numbered description lines isolate each item, the regex wraps each item in a brand new `<ol>` container, causing browser engines to reset every item's counter to `1.`.
     - Parse lines with a stateful loop: match `^(\s*)(\d+)\.\s+(.*)$`, extract explicit starting index `num = parseInt(m[2], 10)`, and output `<ol start="${num}">` and `<li value="${num}">`.
     - Accumulate non-marker continuation lines into the active `<li>` using `<br>` joins.
     - On encountering empty lines, look ahead across whitespace: if the next non-empty line continues the same list type, keep the active `<ol>` or `<ul>` open rather than emitting closing tags or splitting paragraphs inside the list.
     - Style list items in CSS with generous breathing room (`margin-bottom: 12px; line-height: 1.68; color: #1e293b;`).
   - Style list markers with accent color and monospace numerals (`ol li::marker { color: var(--accent-terracotta); font-weight: 700; font-family: var(--font-mono); }`) for clear visual rhythm.
   - Split remaining text by double newlines (`\n\n+`) into distinct paragraphs (`<p>` with `margin-bottom: 12px; line-height: 1.65;`). Convert single newlines (`\n`) inside paragraphs into `<br>`.
   - Block element containment: Never wrap block-level tags (`<h1>`-`<h6>`, `<ol>`, `<ul>`, `<pre>`, `<hr>`, `<blockquote>`) in `<p>` tags; browser parsers auto-close `<p>` on block elements, causing malformed DOM trees and broken spacing.
   - Transform markdown links `[text](url)` to styled anchors with `target="_blank"` and `rel="noopener"`.
   - Markdown Pipe Tables (`| ... |`): Parse pipe-delimited markdown tables into responsive HTML tables (`<table class="md-table">`) wrapped in an overflow container (`overflow-x: auto;`) with alternating zebra striping and tinted headers (`rgba(0, 229, 255, 0.08)`). Do not leave raw markdown table syntax (`|:---|:---|`) unrendered as plain text.
   - Restore code blocks into `<pre><code class="language-...">` containers after paragraph and list assembly.
