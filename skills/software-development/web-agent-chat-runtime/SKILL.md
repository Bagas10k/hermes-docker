# Web Agent Chat Runtime

Bidirectional web chat interfaces and prompt studio environments for autonomous AI agents.

## When to Use
- Web chat interfaces (SaaS dashboards, companion HUDs) for AI agents.
- Prompt builder tools integrated into an active chat canvas.
- Chat bridges (Telegram, WhatsApp) without loop deadlocks.
- Resilient SSE streaming (high TTFT, heartbeats, network auto-retry).
- Eliminating mobile scroll jitter via binary sticky pinning (`isUserPinnedToBottom`) and 60 FPS adaptive typewriter queues.
- Clean message actions (3-dots popovers) and responsive font controls (segmented buttons).

## Supporting References
- `references/sse-resilience-and-claude-reasoning.md`: Detailed specifications for immediate SSE handshakes, keep-alive heartbeat intervals, client-side auto-retry, Claude-style XML block prompt partitioning, response regeneration DB truncation, rAF 60 FPS streaming throttling, mobile IME input safety, drag-and-drop file protection, ObjectURL RAM lifecycle management, and text deliverable anti-HTML wrapping rules with 1-click TXT/DOC export.

## Architecture & Turn Lifecycle

```
[Web Chat Frontend]
       │
       ▼ (POST /api/.../chat { message, agent })
[Backend Bridge / Route]
       │
       ├──> 1. Record User Turn: { role: 'user', sender: '<User Name>', content }
       ├──> 2. Query Model Endpoint: POST /v1/chat/completions (9router / local LLM)
       │       with Persona & Constraints Context
       ├──> 3. Record Assistant Turn: { role: 'assistant', sender: '<Agent Name>', content }
       │
       ▼ (Response { ok: true, userMessage, assistantMessage })
[Web Chat Frontend] ──> Resolves thinking indicator, renders markdown & code blocks
```

## Procedure

1. **Establish State Persistence & Message Schema**:
   Define a unified message contract before building UI:
   `{ id: number, role: 'user' | 'assistant', sender: string, content: string, time: string, metadata?: object }`.
   Store history in a local SQLite table or persistent state file (`~/.local/state/<app>/chat_history.json`).

2. **Decouple Inbound User Turns from Outbound Bot Tools**:
   - For web prompt submissions, dispatch the message directly to the completions/agent execution endpoint as `role: 'user'`.
   - Never invoke outbound bot broadcast tools (e.g. `hermes send --to <target>`) with the raw user prompt. If external channels require mirroring, format explicitly with sender attribution: `[Web Studio] <User>: <prompt>\n<Agent>: <reply>`.

3. **Implement Floating Prompt Dock & Anti-Bleed Layout**:
   - Position floating dock capsules with backdrop blur and high-opacity gradient backing (`linear-gradient(180deg, rgba(..., 0) 0%, rgba(..., 0.85) 15%, #... 40%, #... 100%)`).
   - Calculate container bottom padding strictly exceeding dock height plus gradient threshold: `padding-bottom: calc(var(--dock-height) + 40px);`. This prevents bottom chat bubbles from bleeding behind interactive chips or input textareas.

4. **Zen Minimalist Canvas & Major LLM Parity (ChatGPT & Claude Standards)**:
   - **Zero-Slop Empty State**: Keep the empty state clean, calm, and uncluttered. Forbid sprawling multi-paragraph prompt template cards, tag buttons, and bloated in-canvas prompt crafters unless explicitly requested. Users favor a serene, minimal greeting (e.g. "Ada yang bisa Mumu bantu?", "Model bk aktif • Siap mendampingi") with expansive whitespace.
   - **Zero Emoji Doctrine (Apple SF Symbols Standard)**: Forbid Unicode emojis (`✨`, `🐴`, `●`, `✦`, `👍`, `👎`, `⏱`) across the entire UI, including titles, brand labels, action buttons, toasts, and status pills. Use only crisp, minimalist line-based SVG vector glyphs modeled after Apple's SF Symbols.
   - **In-Dock Agent & Thinking Effort Selectors Alongside Execution Button (ChatGPT & Claude Paradigm)**: Never hide model selection in distant top headers or stack them clumsily in separate bars. Mount controls in a streamlined two-tier dock:
     - **Top Tier**: Expanding auto-growing textarea (`.dock-input-row`).
     - **Bottom Action Tier (`.dock-action-bar`)**: Attachment button on the far left; on the far right, position the Model Picker Pill (`[Mumu bk ▾]`), Thinking Effort Pill (`[Think: Standar ▾]`), and the Execution (Send) Button sitting directly alongside each other.
     - **Pill Button Styling (Frosted White Glass Blur)**: Style pills with translucent frosted white glass blur (`background: rgba(255, 255, 255, 0.76); backdrop-filter: blur(16px); border: 0.5px solid rgba(255, 255, 255, 0.95); color: #1e293b; box-shadow: 0 2px 8px rgba(14, 27, 49, 0.04); border-radius: 9999px;`).
     - **Execution Button (Luminous Blue Gradient)**: Style the send button with a vibrant blue gradient (`background: linear-gradient(135deg, #2b7fff 0%, #0059f7 50%, #0047d4 100%); color: #ffffff; box-shadow: 0 4px 14px rgba(0, 89, 247, 0.32);`).
   - **Dynamic Send / Stop Generation Toggle**: While the AI is generating or streaming, morph the send button (`↑`) into a high-contrast stop button (`■`) wired to `AbortController.abort()` to give users instant cancellation control.
   - **Auto-Expanding Upward Textarea with Continuous Squircles**: Style the input capsule with continuous Apple squircle curves (`border-radius: 24px-26px`). As multi-line prompts are typed, the textarea expands upwards smoothly (`transition: height 0.18s cubic-bezier(0.16, 1, 0.3, 1)`) up to a 140px ceiling with a hidden scrollbar.
   - **Mobile Virtual Keyboard Pinning & Smooth Feed Alignment (`window.visualViewport`)**: Handle mobile software keyboards reliably. Bind both `resize` and `scroll` events on `window.visualViewport` to dynamically calculate `offsetFromBottom = window.innerHeight - (visualViewport.height + (visualViewport.offsetTop || 0))`. When the virtual keyboard pops up (`offsetFromBottom > 30px`), pin `dock.style.bottom = `${offsetFromBottom + 6}px`` and trigger smooth auto-scroll on `#chat-stream` (`chatStream.scrollTo({ top: chatStream.scrollHeight, behavior: 'smooth' })`) so the active message thread stays visible above the dock. When the keyboard closes (`offsetFromBottom <= 30px`), reset `dock.style.bottom = ''` to let CSS `env(safe-area-inset-bottom)` take control cleanly without leaving inline layout residue. Pair with `interactive-widget=resizes-content` in the viewport meta tag.
   - **User Prompt Bubble Sizing & Harmonious Light Blue Gradient**: Size user prompt bubbles strictly to hug prompt content (`width: fit-content; max-width: 82%; margin-left: auto;`) rather than stretching full width. Style with a harmonious light sky-blue pastel gradient (`background: linear-gradient(135deg, #e0f2fe 0%, #bae6fd 50%, #93c5fd 100%);`) paired with deep navy typography (`color: #032b56; font-weight: 600;`), specular highlight rim, and squircle corner radii (`border-radius: 18px 18px 4px 18px`).
   - **Cardless / Unboxed Assistant Editorial Presentation (No Bubble)**: Never enclose assistant responses in rounded cards, borders, or bubble containers on light canvas UIs. Present responses as free-flowing unboxed editorial text directly on the canvas (like Claude and ChatGPT web clients). Enforce high-standard typography:
     - Paragraphs with comfortable vertical rhythm (`margin-bottom: 12px; line-height: 1.7; color: #0f172a;`).
     - Preserved single line breaks (`<br>`) and double-break paragraphs.
     - Sequential ordered numbered steps ("perurutan / tangga": `<ol><li>...</li></ol>`).
     - Clean unordered bullet lists (`<ul><li>...</li></ul>`).
     - Duplex comparison tables (`<table>` with subtle hairline dividers and tinted headers).
     - Bold (`<strong>`) and italic (`<em>`) hierarchies.
     - Dark syntax code blocks with copy affordance.
     - Underneath utility toolbar: Salin, Buat Ulang, and transparent Token & Biaya badge.
   - **Dual-Edge Scroll Opacity Gradient Mask (Top Mascot & Bottom Dock Fading)**: Apply a dual-edge vertical gradient mask to the scrollable chat feed (`-webkit-mask-image: linear-gradient(to bottom, transparent 0px, black 36px, black calc(100% - 90px), transparent 100%); mask-image: linear-gradient(...)`). Messages scrolling up dissolve into opacity 0 before touching the mascot/header boundary, and messages scrolling down dissolve seamlessly into opacity 0 beneath the floating input prompt dock, eliminating all hard clipping seams.

   - **Interactive Live Preview Sandbox (Claude Artifacts / ChatGPT Canvas Paradigm)**: For web code blocks (HTML, SVG, XML), equip the code header with an interactive `Pratinjau` button that launches a frosted glass modal sandbox (`#modal-artifact-preview`). Equip the modal with macOS window dots, a segmented tab switcher (`[Pratinjau] [Kode]`), device viewport toggle (Mobile 390px vs Desktop 100%), source code copy affordance, open in new tab affordance, and close button:

     - When previewing raw SVG or XML snippets, wrap them automatically inside an auto-centered HTML boilerplate canvas (`<!DOCTYPE html><html><body style="margin:0;min-height:100vh;display:flex;align-items:center;justify-content:center;background:#f8fafc;padding:20px;">${svgCode}</body></html>`) so vector graphics render immediately without requiring full HTML scaffolding. On mobile screens ($\le 600\text{px}$), wrap button labels in `<span>` and hide them (`display: none;`) to keep touch targets icon-only and prevent header title vertical wrapping.
   - **1-Click File Export & Disk Persistence**: Mount an `[Unduh File]` button alongside copy controls on every code block. Dynamically map language tags to filenames (`html` $\to$ `landing-page.html`, `js` $\to$ `script.js`, `ts` $\to$ `app.ts`, `tsx` $\to$ `component.tsx`, `jsx` $\to$ `component.jsx`, `py` $\to$ `script.py`, `css` $\to$ `styles.css`, `json` $\to$ `data.json`, `csv` $\to$ `table.csv`, `sql` $\to$ `query.sql`, `sh` $\to$ `run.sh`, `svg` $\to$ `illustration.svg`, `xml` $\to$ `diagram.svg`, `yaml`/`yml` $\to$ `config.yaml`, `toml` $\to$ `config.toml`, `md` $\to$ `catatan.md`). Generate client-side Blob downloads (`URL.createObjectURL(new Blob([code], { type: mime }))`) with haptic feedback. Pair with backend endpoints (`POST /api/.../save-file`) for optional server-side disk writes.
   - **Multimodal Image Cards, Lightbox Modal & Blob Fetch Download**: Parse markdown image syntax `![alt](url)` into a dedicated rounded frosted card (`.chat-image-card`) with loading placeholder, click-to-expand lightbox modal (`#modal-image-lightbox`), caption label, and instant download button. Avoid class names containing `card`, `box`, `panel`, `tile` for image viewer wrappers (e.g. use `.image-viewer-stage`) to prevent automated layout linters from misidentifying empty media containers as abandoned decorative text cards (`EMPTY_DECORATIVE_SLOP`). For image downloads, modern browsers ignore `<a href="url" download>` for cross-origin URLs (opening in a new tab instead); implement an asynchronous blob-fetch handler (`fetch(url, { mode: 'cors' })` $\to$ `res.blob()` $\to$ `URL.createObjectURL(blob)`) with virtual anchor click, falling back to a new tab only if CORS is blocked. Bind URLs and captions strictly via HTML `data-url` and `data-caption` attributes rather than interpolating raw strings into inline `onclick` attributes to prevent quote breakage and XSS.
   - **Generous Bottom Clearance for Floating Docks ("Anti-Ketutup Dock Bawah")**: When a chat interface features an elevated floating input dock (~110px-120px tall) with dual-edge vertical opacity gradient masks, standard bottom padding (`140px-145px`) causes the lower portion of media cards, image captions, and action buttons to remain obscured or faded behind the dock when scrolled to the bottom. Enforce generous bottom padding (`padding: 24px 20px 180px;` on desktop, `padding: 8px 12px 185px;` on mobile) on `#chat-stream` so that all content, captions, and download buttons scroll completely clear of the floating bar with comfortable breathing room. Enable `-webkit-overflow-scrolling: touch;` and slim custom scrollbars (`height: 4px;`) on `<pre>` code elements so wide SVG or JS lines scroll horizontally without clipping.
   - **Silent In-Dock Pill Feedback (Anti-Toast Clutter)**: When users toggle model or reasoning effort selectors in the input dock, update the pill text label directly (`#label-dock-model`, `#label-dock-thinking`) accompanied by an acoustic tick or micro-haptic. Never fire floating toast notifications (`toast("Penalaran: Think: Off")`) for routine dropdown selections; they add visual noise, distract the user, and collide with the character mascot's visor.
   - **Empty Zen State Fast Suggestions**: Beneath the minimal greeting headline, provide 3 compact, frosted quick-action suggestion chips (`.suggestion-chip`, `border-radius: 9999px; background: rgba(255, 255, 255, 0.75); backdrop-filter: blur(14px); border: 0.5px solid rgba(255, 255, 255, 0.95); font-size: 12px; font-weight: 600; color: #1e293b;`). Clicking a chip instantly fills the input and triggers execution, eliminating friction for new sessions.
   - **Floating Jump-to-Bottom Scroll Affordance**: Mount a floating circular button (`#btn-scroll-bottom`, `36px × 36px`, frosted white blur, down chevron icon) positioned above the dock. Listen to chat stream scroll events and reveal it with smooth fade-in whenever the user is scrolled up $> 160\text{px}$ from the bottom, snapping back down on click with `behavior: 'smooth'`.
   - **Table Containment Wrapping (`.table-wrap`) & Micro-Scrollbars**: Always wrap parsed markdown tables in an independent overflow container (`.table-wrap`, `width: 100%; overflow-x: auto; -webkit-overflow-scrolling: touch; border-radius: 12px; border: 0.5px solid rgba(14, 27, 49, 0.1); box-shadow: 0 2px 8px rgba(14, 27, 49, 0.03); scrollbar-width: thin; scrollbar-color: rgba(14, 165, 233, 0.35) transparent;`) with dedicated thin scrollbars (`.table-wrap::-webkit-scrollbar { height: 4px; } .table-wrap::-webkit-scrollbar-thumb { background: rgba(14, 165, 233, 0.35); border-radius: 4px; }`). This isolates wide multi-column tables, prevents horizontal layout disruption on mobile, and gives users an immediate visual cue that content is scrollable horizontally.
   - **Critically Damped Mascot Kinematics (Anti-Jitter, Zero Layout Thrashing & GPU Layer Promotion)**: Never attach `transition: transform` in CSS to elements whose transforms are animated every frame via JavaScript `requestAnimationFrame`. Simultaneous CSS cubic-bezier transition interpolation fights the 60 FPS JS solver on every frame, generating violent high-frequency jitter (*getar hebat*). Use critically damped spring physics ($k \approx 0.065, c \approx 0.84$, resting dead-zone clamp $< 0.001$, gentle impulse $-0.14$), promote to GPU compositing layers (`will-change: transform; transform: translateZ(0); -webkit-backface-visibility: hidden; backface-visibility: hidden;`), and keep the outer container card stationary during taps. Cache geometry anchors (`faceCenterX`, `faceCenterY`) outside the rAF loop, recalculating strictly on passive `resize` and `scroll` events to completely eliminate forced synchronous layout thrashing (`getBoundingClientRect()` in rAF). Gate style writes behind an explicit perceptual delta threshold (e.g. eye $> 0.01\text{px}$, sheen $> 0.8\%$) and halt writes at rest.
   - **Assistant Message Action Toolbar & Transparent Token Cost Metric**: Attach a clean utility toolbar directly below each assistant response containing "Salin" (copy text with robust clipboard fallback and inline checkmark feedback), "Buat Ulang" (clean turn-aware regeneration replacing the assistant response in-place), and a transparent token cost badge (e.g. `45 token • Biaya: $0.0001`) with tooltip clarification to prevent users from mistaking API compute tokens for word/sentence counts.
   - **Turn-Aware In-Place Branching / Response Regeneration (ChatGPT & Claude Standards)**: Pass the clicked button element (`this`) into `regenerateResponse(btn)`. Identify the target assistant message row, find its preceding user turn in DOM, truncate all subsequent child rows from the container, slice the active conversation state up to that user prompt (`currentConversation.slice(0, userIdx + 1)`), and stream the regeneration in-place. If triggered without a button reference, default to popping only the last assistant turn. This guarantees conversational linearity and prevents duplicate or out-of-order bubbles.
   - **Session State Tracking & Sanitized History Titles**: Track an `activeSessionId` across multi-turn exchanges to update existing session records in `localStorage` or SQLite instead of prepending duplicate entries. When auto-generating session titles from the initial user prompt, strip custom instructions or context headers via regex (`firstUserMsg.content.replace(/^\[(?:Konteks|Gaya)[^\]]*\]\s*/gim, '').trim()`) before slicing to title length (`slice(0, 36)`), ensuring the history drawer displays the user's authentic question cleanly. On new conversation dispatch, reset `activeSessionId = null`.
   - **Backend Thinking Effort Synchronization & Usage Token Grounding**: Wire client-side reasoning effort pills (`Think: Off`, `Think: Standar`, `Think: Mendalam`) to the backend API. Calibrate backend system personas, temperature, and token ceilings:
     - `off`: `temperature: 0.4`, `max_tokens: 850`, direct solutions without preamble.
     - `standard`: `temperature: 0.7`, `max_tokens: 1500`, balanced reasoning.
     - `deep`: `temperature: 0.7`, `max_tokens: 2500`, formal causal decomposition, mathematical bounds, and trade-off analysis.
     Pass provider `usage.total_tokens` directly to client metadata rather than relying on crude character-length estimations.
   - **Mathematical & Scientific Formula Typography (KaTeX Integration)**: Never leave raw LaTeX formulas (`$$...$$`, `$ ... $`, `\lambda`, `\rho`, `\sigma`, `\ge`) as unparsed text strings. Prior to general HTML escaping, extract display math `$$...$$` and inline math `$ ... $` (ignoring currency numbers like `$10` or `$0.0015`) into collision-free placeholders (`___MATHBLOCK_n_END___`, `___INLINEMATH_n_END___`). Compile formulas using KaTeX (`katex.renderToString(formula, { displayMode, throwOnError: false })`), and store KaTeX bundles (`katex.min.js`, `katex.min.css`, and woff2 fonts) locally under vendor paths for zero-latency, offline rendering.
   - **Universal Robust Clipboard Copy Fallback with Inline Feedback**: Modern browsers reject `navigator.clipboard.writeText()` in iframes, headless CDP, unfocused tabs, or non-secure contexts. Always wrap clipboard writes with an automated fallback using a temporary hidden `<textarea>` and `document.execCommand('copy')`. Immediately update the copy button to an emerald checkmark (`#10b981`) and "Tersalin" label for 1.8s for direct visual confirmation.
   - **Real Source Code / Text Attachment Ingestion**: When users attach files via file input, do not merely insert dummy text (`[Lampiran: file.js]`). Read text/code files (`.js`, `.ts`, `.py`, `.html`, `.css`, `.json`, `.sql`, etc. up to 200KB) via `FileReader.readAsText()` and embed them into the textarea wrapped in markdown code blocks with matching language tags.
   - **Global Keyboard Accessibility (Escape Key Dismissal)**: Bind a global `keydown` event listener for the `Escape` key to instantly dismiss active artifact sandbox modals, lightbox image viewers, dock dropdown popovers, and sliding chat history drawers.
   - **Autoplay Audio Context Unlock on First User Gesture**: To comply with modern browser autoplay policies (especially iOS Safari and Android Chromium), bind a one-time `pointerdown` and `keydown` listener to resume or initialize `AudioContext` on the first touch or tap, ensuring subsequent acoustic cues never fail silently.
   - **Featherlight 120 FPS Text Reveal Animation**: In streaming responses, animate text smoothly with a micro vertical glide and opacity fade (`@keyframes iosTextReveal { from { opacity: 0; transform: translateY(6px); } to { opacity: 1; transform: translateY(0); } }`, `animation: iosTextReveal 0.22s cubic-bezier(0.16, 1, 0.3, 1) forwards; will-change: opacity, transform;`). Strictly forbid animating `filter: blur(...)` during streaming text reveals; blur animation triggers expensive off-screen GPU framebuffer passes per frame and causes severe mobile stutter.
   - **Compact Settings Popover Dropdown (Anti-Full-Screen Modal)**: Forbid intrusive full-screen settings modals. Mount an elegant top-right floating iOS popover (`width: ~280px-300px`) beneath the settings gear with horizontal sliding submenus (`‹ Kembali`):

   - **Slide-Over Chat History Drawer**: Provide a left-hand frosted glass drawer (`width: ~310px`) triggered by a top-left clock/history icon for browsing, resuming, and deleting past conversation sessions stored in `localStorage`.
   - **Universal Power Keyboard Shortcuts (`Escape`, `Cmd/Ctrl+K`, `Cmd/Ctrl+Shift+O`)**: Equip the chat runtime with standard desktop and tablet shortcuts: `Escape` dismisses all active modal overlays, image lightboxes, history drawers, and dock popovers; `Cmd/Ctrl+K` immediately focuses and selects the prompt textarea without mouse navigation; `Cmd/Ctrl+Shift+O` triggers a new conversation session.
   - **Dynamic Empty-State Subtitle on Model / Persona Switching**: When the user switches agent personas or models via in-dock or header selectors, update the empty-state hero subtitle dynamically to reflect the active role's specialization (e.g. Architect, Fullstack Dev, General Companion), providing immediate cognitive reassurance that the selection took effect before dispatching a prompt.
   - **Tactile Visual Feedback on File Exports & Downloads**: Just like copy buttons, file export buttons (`[Unduh File]`) must provide immediate inline visual feedback upon click: transform the button innerHTML to display an emerald checkmark (`#10b981`) and confirmation label ("Diunduh") for 1.8s, accompanied by an acoustic finish chime and haptic feedback to prevent duplicate clicks during background Blob downloads.
   - **Mascot Apex Negative Space & Headroom Clearance Invariant**: When a 3D or vector mascot straddles the top border of the main living container card, calculate clearance between the bottom baseline of the top navigation bar and the highest tip of the mascot (antenna orb + halo glow). Maintain at least $24\text{px}-32\text{px}$ of open vertical breathing space (e.g. desktop container `top: 104px-108px`, mobile `top: 84px-86px`) to prevent visual crowding and header collision.
   - **Continuous Liquid Opacity Gradient Masks (No Harsh Cutoffs)**: Avoid harsh horizontal blur cuts. Use `-webkit-mask-image: linear-gradient(to bottom, black 70%, transparent 100%)` for sticky headers and `linear-gradient(to top, ...)` for bottom docks so blurs feather seamlessly into the canvas.
   - **Harmonious Multi-Stop Blue Gradient User Bubble (Apple iOS iMessage Standard)**: Forbid flat dark navy or dull slate fills for user prompt bubbles on light-mode or pastel canvases. Style user prompt bubbles with a luminous, seamless multi-stop blue gradient (`linear-gradient(135deg, #3b82f6 0%, #2563eb 32%, #1d4ed8 68%, #1e40af 100%)`), specular top rim highlight (`inset 0 1px 1.5px rgba(255, 255, 255, 0.5)`), hairline border (`0.5px solid rgba(255, 255, 255, 0.35)`), colored diffuse ambient glow (`box-shadow: 0 6px 20px rgba(37, 99, 235, 0.28)`), and an asymmetrical squircle corner radius (`border-radius: 20px 20px 4px 20px`) anchoring the lower-right edge to the sender.
   - **Code Economy & Anti-Sprawl Architecture**: Consolidate CSS with semantic variables, eliminate dead preset text blobs and abandoned modal DOM, and keep single-file web UIs under clean, modular bounds (~1,000–1,500 lines) instead of sprawling into bloated 4,000-line monolithic files.
   - **Multi-Turn Context Decoupling & Session Boundary Isolation**: Never rely solely on a single global backend history log for active session inference. When dispatching `POST /api/chat`, transmit the caller's active session dialogue context (`context: currentConversation.slice(-8)`). The backend must prioritize `req.body.context` over global disk files, isolating conversations cleanly when users switch sessions or trigger `New Chat`.
   - **Dynamic Real-Time Server Telemetry & Local Vault Grounding (Zero-Latency Local RAG)**: Empower web chat LLMs with empirical system observability and internal knowledge recall without external dependencies:
     - *Live Telemetry*: When the prompt queries system health, RAM, CPU, or active services (`pm2`, ports, memory), execute a synchronous, bounded OS/process inspection (<50ms: `os.totalmem()`, `os.freemem()`, `os.loadavg()`, `pm2 jlist`) and inject real metrics into the system prompt with strict directives to quote the physical numbers in structured tables.

This grounds model reasoning in verified facts and eliminates hallucinations.

## Pitfalls

- **The Missing `stop_reason` State Machine Pitfall**: Treating LLM streaming responses purely as string concatenation without tracking the reason generation terminated (`end_turn`, `tool_use`, `max_tokens`) breaks autonomous tool execution and continuation handling. Always normalize upstream gateway finish reasons into explicit `stop_reason` states.
- **The Unstructured Context Bleed Pitfall**: Dumping system instructions, developer personas, user memories, and uploaded document text into flat concatenated strings causes instruction cross-contamination and prompt injection vulnerabilities. Use explicit XML demarcation tags (`<system_instructions>`, `<user_memories>`, `<attached_documents>`) to maintain clean contextual boundaries.
- **The Empty-Password Admin Authentication Bypass Trap**: In 1-step or passwordless registration routes, checking `if (user.password_hash && password)` allows attackers to bypass password verification by simply submitting an empty password string (`password = ''`), granting unauthenticated access to existing accounts. Always enforce strict password verification for privileged roles (`admin`, `master`) regardless of input presence (`if (isAdmin && (!password || !password.trim())) throw new Error(...)`).
- **The Unbounded Streaming Concurrency Saturation Trap**: Exposing SSE completion endpoints without concurrency bounds allows automated scripts or concurrent user tabs to trigger dozens of parallel inference streams, exhausting local GPU/CPU VRAM and causing 60-second timeouts. Enforce per-user ($\le 2$) and global ($\le 6$) active stream bounds with HTTP 429/503 responses.
- **The Stale Guest Account Bloat Trap**: Offering 1-click "Masuk sebagai Tamu" accounts without automatic time-to-live (TTL) expiration causes thousands of ephemeral rows to accumulate in SQLite `users`, `conversations`, and `messages` tables over time. Implement a periodic garbage collection routine (`DELETE FROM users WHERE (role = 'guest' OR email LIKE 'tamu_%') AND last_login < datetime('now', '-7 days')`) using `.unref()` timers.
- **The Dummy Binary Attachment Trap**: Inserting dummy labels (`[Lampiran: file.pdf]`) into prompts without extracting text causes the LLM to hallucinate or apologize for not being able to read documents. Use server-side extraction (`pdf-parse`, `mammoth`) to embed actual text into the context payload.
- **Cross-Tab Quota Desynchronization Trap**: Updating user balances only within the active tab causes background tabs to display stale token balances until refreshed, leading to unexpected 402 quota-exhausted errors on subsequent prompts. Post balance updates to a `BroadcastChannel` to keep all open tabs synchronized.
- **The Node.js `req.on('close')` SSE Premature Abort Trap**: Binding an abort controller to `req.on('close', () => abortController.abort())` in a POST handler with a JSON body causes Node's incoming request stream to emit `'close'` as soon as the POST body finishes reading, instantly aborting outbound upstream LLM fetches before any chunks stream back. Always listen to client disconnection on `res.on('close', () => { if (!res.writableEnded) abortController.abort(); })`.
- **The Missing `[DONE]` Gateway Stream Hang Pitfall**: Many OpenAI-compatible model routers and gateways (e.g. 9Router, vLLM, local reverse proxies) terminate completion chunks with `finish_reason: "stop"` or `"end_turn"` without sending an explicit `data: [DONE]` marker, keeping the HTTP keep-alive connection open. An SSE chunk reader checking only `dataStr === '[DONE]'` hangs indefinitely until socket timeout. Always break the stream parser loop if `dataStr === '[DONE]' || parsed?.choices?.[0]?.finish_reason === 'stop' || parsed?.choices?.[0]?.finish_reason === 'end_turn'`.
- **The Dynamic SQL Re-compilation in SSE Routes Trap**: Preparing SQL statements inside request handlers or streaming callbacks forces SQLite to re-parse and compile the SQL query on every turn or chunk. Cache all prepared statements at service initialization (`stmts = { saveMsg: db.prepare(...), deduct: db.prepare(...) }`), and wrap multi-step quota mutations and message inserts inside `db.transaction(...)` for zero-overhead, crash-safe atomic consistency.
- **The Fragmented `<ol>` Number Reset Pitfall ("Nomor Urut 1 Terulang")**: Grouping numbered list lines (`\d+\. `) into `<ol><li>...</li></ol>` via single-line regex passes breaks when items contain multi-line descriptions or double newlines between steps. The parser matches each numbered line separately, wrapping each in an isolated `<ol>` element. The browser resets list numbering on every isolated `<ol>`, displaying `1.` on every single item in the UI. Either accumulate paragraph continuation lines into the active `<li>` container, or parse list numbers explicitly into structured elements with preserved index values.
- **The Mobile Scroll Inset & Dock Submersion Trap ("Ketutup Dock Bawah & Terpotong Atas")**: Sizing chat scroll containers with tight vertical padding under sticky mascot headers and above floating input docks causes double layout degradation: the top text line is clipped in half by the upper alpha fade mask when scrolled up, and the bottom conclusion or action buttons are submerged behind the floating dock capsule. Enforce `padding-top: max(32px, env(safe-area-inset-top) + 24px)` to clear upper gradient masks, and enforce `padding-bottom: calc(var(--dock-height, 120px) + 80px)` (at least `210px-240px` on mobile) so the lowest message clears the dock with comfortable breathing space.
- **Naïve RegEx List Splitting**: Splitting numbered lists with single-line regexes breaks multi-line explanations or indented paragraphs, ejecting the explanation out of the `<ol>` container. Use a tokenizer that accumulates continuation lines into the current list item.
- **Block Elements Inside `<p>`**: Wrapping raw markdown outputs in `<p>` causes browsers to prematurely terminate paragraphs on headers, lists, and code blocks, resulting in malformed DOM trees and collapsed margins.
- **The Bot Echo Trap**: Piping user chat inputs into outbound bot dispatchers (e.g. `hermes send --to telegram`) transmits the prompt under the bot's token credentials. In mirrored channels the prompt arrives as an agent message, and the agent's self-message filter drops it to prevent infinite loops, leaving the prompt unaddressed.
- **Mobile Multi-Line Placeholder Truncation**: Long placeholder text in compact mobile input capsules wraps onto a second line, causing vertical glyph clipping against container borders. Always enforce single-line placeholder styling with `white-space: nowrap; text-overflow: ellipsis;`.
- **The Inset Mobile Container Squeeze Trap ("Kolom Chat Sempit")**: Keeping desktop card margins (`left/right: 8px-16px`) and forcing side-by-side avatar rows on mobile restricts assistant reading width to $<300\text{px}$, creating a cramped receipt-like text column. On mobile ($\le 768\text{px}$), enforce full-bleed containerization (`left: 0; right: 0; border: none;`), stack the avatar above text or use an inline header, and expand the input field tap target to `min-height: 38px-42px; font-size: 15px;`.
- **The Tiny Slit Textarea Tap Target**: Setting mobile chat textareas to single-line 22px-26px heights creates an uncomfortable, cramped tap zone on touchscreens. Enforce `min-height: 38px-42px; font-size: 15px;` with `bottom: max(8px, env(safe-area-inset-bottom, 8px))` to maintain thumb comfort and prevent iOS viewport zoom.

Always transform the export button to an emerald checkmark (`#10b981`) and confirmation label ("Diunduh") for 1.8s, accompanied by audio and haptic cues.
- **Missing Universal Keyboard Shortcuts Friction**: Lacking standard shortcuts like `Cmd/Ctrl+K` (focus prompt input), `Cmd/Ctrl+Shift+O` (new chat), and `Escape` (dismiss active popovers and overlays) introduces unnecessary pointer friction for power users.
- **Global Disk State Context Contamination Trap**: Slicing the last turns from a single server-wide chat log file for multi-turn inference causes different chat sessions and newly initialized threads to inherit dialogue history from previous unrelated exchanges. Always transmit and prioritize the frontend session's active dialogue context (`context: currentConversation.slice(-8)`).
- **The Speculative Hallucination on Server Telemetry**: Allowing an LLM to guess memory usage or service status when asked about server health leads to fabricated stats or generic terminal command regurgitation. Synchronously inspect live system metrics and inject verified data directly into the system context.
- **The "@" Persona Selector Mismatch**: Checking `lower.includes('@architect')` while the UI dropdown sends `agent: 'architect'` silently drops the persona selection, falling back to the default general assistant. Always normalize both tag identifiers and text mentions (`agentTag === 'architect' || lower.includes('@architect')`).
- **Monolithic XML Suppression of SVG Previews**: Restricting live preview buttons strictly to `cleanLang === 'svg'` leaves SVG diagrams wrapped inside `xml` code blocks unviewable in the artifact sandbox. Check `cleanLang === 'svg' || (cleanLang === 'xml' && code.includes('<svg'))`.
- **The Blocking LLM Wait Trap ("Loading Lama Tanpa Progres")**: Forcing users to stare at a static loading indicator for 5–10 seconds while the model generates its entire answer creates high perceived latency and uncertainty. Always implement native SSE token streaming (`text/event-stream`) to reduce Time-to-First-Token (TTFT) to under 1 second.
- **Chunk Fragmentation JSON Parse Crash**: Assuming every SSE event chunk delivers a single complete, well-formed JSON line causes `JSON.parse` syntax crashes when network TCP packets split a payload across packet boundaries. Always buffer stream chunks, split by newline (`buffer.split('\n')`), and retain the uncompleted trailing string in the buffer for the next iteration.
- **The Aborted Stream UI Crash Pitfall**: Catching `AbortError` from user cancellation with generic network error handlers renders an ugly red failure banner across the chat. When `err.name === 'AbortError'`, suppress error banners, preserve the partially received text bubble, and reveal standard action buttons (Salin, Buat Ulang) immediately.
- **Aggressive Streaming Scroll-Snapping Pitfall**: Unconditionally executing `chatStream.scrollTop = chatStream.scrollHeight` on every streaming chunk forcibly snatches the viewport down when users try to scroll up to inspect previous answers during live generation. Always guard auto-scroll behind proximity checks (`isNearBottom < 120px`).
- **The Streaming Code Block Layout Shift (CLS) Pop Trap**: Omitting odd-parity backtick auto-closure in markdown streaming parsers leaves code blocks rendered as raw unformatted text until generation finishes, abruptly jarring the reader with sudden card reflow when triple backticks finally arrive. Check odd backtick parity and auto-close parse buffers on the fly.
- **The Aborted Stream UI Limbo Trap**: Merely catching `AbortError` without calling `streamingRow.finish()` leaves the `.typing-cursor` blinking indefinitely, keeps action buttons hidden, and discards partial output from conversation state and storage. Finalize the active row immediately on abort with the partial text preserved.
- **The Unchecked Accidental Session Deletion Trap**: Binding raw click-to-delete handlers directly to history list item trash icons without tap confirmation causes accidental thumb taps on narrow mobile touch targets to permanently destroy multi-turn sessions. Always require two-step inline confirmation or verification toasts before purging records.
- **Generic Code Download Naming Pitfall**: Defaulting code file downloads indiscriminately to static generic filenames (e.g. `mumu-script.js` or `script.py`) forces users to manually rename every saved file. Always inspect the first line of the code block for file comment headers (`// server.js`, `# run.py`, `<!-- index.html -->`) to extract and apply the contextual filename automatically.
- **The Single Paperclip / Raw Attachment Dump Trap**: Using a single ambiguous paperclip button or dumping raw file text directly into the prompt textarea overwhelms the input box, disrupts prompt typing, and prevents users from cleanly managing or removing attachments. Provide dedicated Photo and Document triggers, surface visual preview chips with remove buttons in an attachment tray, and defer prompt structuring to dispatch time.
- **The Clipboard Screenshot Rejection Trap**: Omitting a `paste` event handler on chat textareas forces users to save screenshots to local disk before opening a file picker, introducing major friction during visual QA and bug reporting. Intercept `clipboardData.items` for `image/*` files and ingest directly into the attachment tray.
