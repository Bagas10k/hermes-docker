# Authoritative Sources

These sources inform the skill. Use principles rather than copying a platform's visual style blindly.

## Material Design 3

Spacing:
https://m3.material.io/styles/spacing

Key idea: spacing is categorized into padding, gaps, and margins and uses an 8dp baseline scale that can adapt to context.

## Apple Human Interface Guidelines

Layout:
https://developer.apple.com/design/human-interface-guidelines/layout

Buttons:
https://developer.apple.com/design/human-interface-guidelines/buttons

Accessibility:
https://developer.apple.com/design/human-interface-guidelines/accessibility

Key ideas: consistent layout, visual hierarchy, adequate spacing around controls, platform-aware hit regions, responsive/adaptive structure.

## WCAG 2.2

Target Size Minimum, SC 2.5.8:
https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum

Target Size Enhanced, SC 2.5.5:
https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced

Key ideas: pointer targets need adequate size or spacing; 24x24 CSS px is the AA minimum criterion with exceptions, while 44x44 CSS px is the enhanced AAA criterion with exceptions.
