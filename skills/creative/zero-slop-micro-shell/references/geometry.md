# Geometry scope
G0 joins position; G1 joins tangent direction; G2 additionally joins geometric curvature. C2 concerns derivatives under a parameterization and is not synonymous with G2. For a radius-r circular arc meeting a straight edge, curvature changes from 0 to 1/r, so tangency alone does not provide G2.

For the unit Lamé curve x^4+y^4=1, near x=0 use the regular graph y=(1-x^4)^(1/4). Its slope and second derivative tend to 0; curvature |y''|/(1+y'^2)^(3/2) therefore tends to 0. Reflections give smooth axis joins and permit zero-curvature attachment to straight edges. This is analytic geometry, not certification of browser tessellation or CSS implementation. Numeric tests corroborate a limit; the formula provides the argument.

MDN defines CSS superellipse(K) using exponent 2^K. Squircle is K=2, exponent 4. Border-radius alone remains the rounded fallback. A 72-segment lineTo outline is polygonal and cannot establish G2.
