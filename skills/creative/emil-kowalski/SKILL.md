# Emil Kowalski UI & Animation Craft

Encoded principles of Emil Kowalski (creator of Vaul, Sonner, and animations.dev) for world-class UI polish, spring physics, and fluid micro-interactions.

## Core Rules
1. **Motion with Intent:** Never animate for decoration. Motion must communicate state change, spatial continuity, or direct feedback.
2. **Spring Physics over Linear Timing:** Use damped spring curves (`cubic-bezier(0.16, 1, 0.3, 1)` or spring stiffness/damping) that feel physical and interruptible.
3. **Interruptibility:** Every running animation must be interruptible mid-flight without snapping or layout glitch.
4. **Hardware Acceleration:** Only animate `transform` and `opacity`. Never trigger layout recalculation (`width`, `height`, `margin`, `padding`).
5. **Invisible Polish:** Button press compression (`scale(0.97)`), subtle haptic feedback, tactile active states, and seamless drawer exits.
